**Interview Prep** is hands-on practice for data and programming
interviews — and like everything on Dataslope, it's **free and runs
entirely in your browser**. No sign-up, no install.

The difference from a wall of "top 50 questions" lists: here you can
**actually run the answer**. SQL questions execute against a real
in-browser database, coding questions run against a test suite, and
concept checks explain every option — so you build intuition, not just
recognition.

## Prep by role

Pick the track that matches the job you're targeting. Each role page
outlines what interviewers tend to probe, then links to practice
questions.

- **[Data Analyst](/interview/data-analyst)** — SQL fluency, aggregation, and turning data into answers.
- **[Data Scientist](/interview/data-scientist)** — statistics, modeling, and experiment design.
- **[Data Engineer](/interview/data-engineer)** — SQL at depth, pipelines, modeling, and systems.
- **[Analytics Engineer](/interview/analytics-engineer)** — the dbt/warehouse layer between data engineering and analytics.
- **[Machine Learning Engineer](/interview/machine-learning-engineer)** — ML fundamentals plus production engineering.
- **[Backend / Software Engineer](/interview/backend-engineer)** — data structures, algorithms, and language fundamentals.

## How to use it

1. Skim the role overview to see what's in scope.
2. Work the interactive questions — write the query or function and run it.
3. When you're stuck on a concept, the related [Learn](/learn) course goes deeper.

## Q&A

### What's the difference between `loc` and `iloc`?

`loc` selects by **label** (index/column names); `iloc` selects by
**integer position**.

```python
df.loc[3, "amount"]    # row with index label 3, column "amount"
df.iloc[3, 1]          # 4th row, 2nd column, regardless of labels
df.loc[df.region == "North"]   # boolean mask (label-based)
```

A common gotcha: after filtering, the index labels no longer match
positions, so `loc[0]` may raise while `iloc[0]` still works.

### What does `groupby` return, and what is the "split-apply-combine" pattern?

`groupby` **splits** rows into groups by key, lets you **apply** an
aggregation/transform per group, then **combines** the results. Grouping
one column and aggregating returns a **Series** indexed by the group
keys; aggregating several returns a **DataFrame**.

```python
df.groupby("region")["amount"].sum()              # Series
df.groupby("region").agg(total=("amount", "sum"),
                         n=("amount", "size"))     # DataFrame
```

### When do you use `merge` vs `concat` vs `join`?

- **`merge`** — SQL-style joins on key columns (`how="inner"|"left"|...`).
- **`concat`** — stack DataFrames vertically (more rows) or horizontally (more columns), aligning on the index.
- **`join`** — convenience for merging on the **index**.

Reach for `merge` for "combine on a key," `concat` for "stack these together."

### How do you handle missing data?

Detect with `isna()`/`notna()`; then **drop** (`dropna()`) or **fill**
(`fillna(value)`, forward/backward fill). Choose based on why it's
missing and how much: dropping a few rows is fine; dropping a column
that's 60% null often isn't. Beware that `NaN != NaN`, so compare with
`isna()`, not `== NaN`.

### Why can `SettingWithCopyWarning` appear, and how do you avoid it?

It warns that you may be assigning to a **view** (a slice) rather than
the original frame, so the write might not "stick." Avoid it by doing the
assignment in one `loc` call on the original:

```python
df.loc[df.region == "North", "amount"] = 0   # clear, in-place
```

### How does boolean filtering work in pandas?

You create a boolean Series by applying a comparison to a column, then
pass it inside `df[...]` or `df.loc[...]`. Combine conditions with `&`
(and), `|` (or), and `~` (not), and always wrap each condition in
parentheses because of Python operator precedence.

```python
mask = (df["amount"] > 100) & (df["region"] == "North")
result = df.loc[mask]
```

### What is the difference between `transform` and `agg` in a groupby?

`agg` reduces each group to a scalar (fewer rows); `transform` returns a
Series of the **same length as the original DataFrame**, broadcasting the
group result back to every row. `transform` is useful for creating
group-level features without losing the original index.

```python
df["group_mean"] = df.groupby("region")["amount"].transform("mean")
```

### How do you reshape data from wide to long format?

Use `melt`. It unpivots specified value columns into two columns: one for
the variable name and one for the value. The opposite (long to wide) is
`pivot` or `pivot_table`.

```python
df_long = df.melt(
    id_vars=["customer_id"],
    value_vars=["q1_sales", "q2_sales"],
    var_name="quarter",
    value_name="sales",
)
```

### What is `pivot_table` and how does it differ from `pivot`?

`pivot_table` is like a spreadsheet pivot: it groups by index and columns
and applies an aggregation function (default `mean`). `pivot` is a
simpler reshape with no aggregation — it requires unique (index, columns)
combinations or it raises an error.

```python
pt = df.pivot_table(
    index="region",
    columns="category",
    values="amount",
    aggfunc="sum",
    fill_value=0,
)
```

### What is a categorical dtype and why use it?

Converting a string column with low cardinality to `category` dtype
stores integer codes internally instead of repeated strings, saving memory
and speeding up `groupby` and sorting. Use `df["col"].astype("category")`.
Ordered categoricals also allow meaningful comparisons like `small < medium < large`.

### How do you sort a DataFrame and rank values?

`sort_values(by="col", ascending=False)` sorts rows. `df["col"].rank()`
assigns ranks, with `method="dense"` for no gaps and `pct=True` for
percentile ranks.

```python
df_sorted = df.sort_values(by="amount", ascending=False)
df["rank"] = df["amount"].rank(method="dense", ascending=False)
```

### What does `value_counts` do?

`Series.value_counts()` returns a Series of unique values and their
counts, sorted by count descending. Pass `normalize=True` to get
proportions, `dropna=False` to include NaN counts.

```python
df["region"].value_counts(normalize=True)
```

### How do you work with datetime data in pandas?

Parse with `pd.to_datetime(df["col"])`, then access components via the
`.dt` accessor: `.dt.year`, `.dt.month`, `.dt.day_of_week`, etc.
`resample("ME")` down-samples a DatetimeIndex to monthly periods for
time-series aggregations.

```python
df["date"] = pd.to_datetime(df["date"])
df["month"] = df["date"].dt.to_period("M")
monthly = df.set_index("date").resample("ME")["amount"].sum()
```

### What does `resample` do and when do you use it?

`resample` is the time-series equivalent of `groupby`: it bins rows into
time periods (e.g., `"D"` for daily, `"ME"` for month-end, `"YE"` for
year-end) and applies an aggregation. The DataFrame index must be a
`DatetimeIndex`.

### What is method chaining and why is it useful?

Method chaining applies multiple DataFrame operations in a single
expression, reading top-to-bottom. It avoids intermediate variables,
keeps intent clear, and is easy to read when formatted with parentheses.

```python
result = (
    df
    .query("amount > 0")
    .assign(tax=lambda x: x["amount"] * 0.08)
    .groupby("region")["tax"]
    .sum()
    .reset_index()
    .rename(columns={"tax": "total_tax"})
)
```

### What is the difference between a view and a copy in pandas?

A **view** shares memory with the original DataFrame; modifying it can
change the original. A **copy** is independent. Slicing with `[]` may
return either depending on the operation. Use `.copy()` explicitly when
you need an independent copy to avoid `SettingWithCopyWarning`.

```python
subset = df[df["region"] == "North"].copy()
subset["amount"] = 0   # safe — won't touch df
```

### How do you apply a custom function to each row or column?

`apply` runs a function along an axis. `axis=0` applies per column;
`axis=1` applies per row. For element-wise operations on a single Series,
`map` (or the older `applymap` / new `map` on DataFrames) is available.

```python
df["discounted"] = df["amount"].apply(lambda x: x * 0.9 if x > 100 else x)
```

### Why is vectorization preferred over `apply` with a lambda?

Pandas and NumPy vectorized operations run in compiled C code and process
all elements in one call — typically 10-100x faster than a Python-level
loop inside `apply`. Use `apply` only when no vectorized equivalent
exists.

```python
# Vectorized (fast)
df["discounted"] = df["amount"] * 0.9

# apply (slow on large frames)
df["discounted"] = df["amount"].apply(lambda x: x * 0.9)
```

### How do you detect and drop duplicate rows?

`duplicated()` returns a boolean Series; `drop_duplicates()` removes
them. Pass `subset` to check only specific columns, and `keep="last"` to
keep the last occurrence instead of the first.

```python
df.duplicated(subset=["email"]).sum()        # count dupes
df_clean = df.drop_duplicates(subset=["email"], keep="first")
```

### How do you rename columns in pandas?

Use `df.rename(columns={"old": "new"})` for targeted renames, or assign
to `df.columns` directly to replace all names at once.

```python
df = df.rename(columns={"cust_id": "customer_id", "amt": "amount"})
```

### How do you select columns by dtype?

Use `df.select_dtypes(include=...)` or `df.select_dtypes(exclude=...)`.
Common dtype strings: `"number"`, `"object"`, `"datetime64"`, `"category"`.

```python
numeric_cols = df.select_dtypes(include="number")
```

### What does `fillna` with `ffill` or `bfill` do?

`ffill` (forward fill) propagates the last valid value forward in the
index; `bfill` (backward fill) uses the next valid value. Both are
common for time-series data where a missing reading should inherit the
nearest observed value.

```python
df["price"] = df["price"].ffill()
```

### How do you perform a conditional column assignment similar to SQL CASE?

Use `numpy.where` for a single condition or `numpy.select` for multiple
conditions — both are vectorized.

```python
import numpy as np

df["size"] = np.where(df["amount"] >= 500, "Large", "Small")

conditions = [df["amount"] >= 500, df["amount"] >= 100]
choices    = ["Large", "Medium"]
df["size"] = np.select(conditions, choices, default="Small")
```

### How do you merge DataFrames on multiple keys?

Pass a list to the `on` parameter (if the key names are identical in both
frames) or use `left_on` and `right_on` lists.

```python
result = pd.merge(
    orders, products,
    left_on=["product_id", "warehouse_id"],
    right_on=["id", "warehouse_id"],
    how="left",
)
```

### How do you compute a percentage of total within a group?

Use `transform` to broadcast the group total back to each row, then divide.

```python
df["pct_of_region"] = (
    df["amount"] / df.groupby("region")["amount"].transform("sum") * 100
)
```

### How do you read and write CSV and Excel files?

`pd.read_csv("file.csv")` and `df.to_csv("out.csv", index=False)` for
CSV. `pd.read_excel("file.xlsx", sheet_name="Sheet1")` and
`df.to_excel("out.xlsx", index=False)` for Excel (requires `openpyxl`).

### What is the `query` method?

`df.query("amount > 100 and region == 'North'")` filters rows using a
string expression. It is readable for simple filters and supports
referencing external variables with the `@` prefix.

```python
threshold = 100
df.query("amount > @threshold")
```

### How do you check the shape, dtypes, and memory usage of a DataFrame?

`df.shape` returns `(rows, cols)`. `df.dtypes` lists each column's dtype.
`df.info()` prints both plus non-null counts and approximate memory usage
in one call. For precise memory, use `df.memory_usage(deep=True).sum()`.

### How do you concatenate DataFrames vertically and reset the index?

Pass a list of DataFrames to `pd.concat` with `axis=0` (the default).
Add `ignore_index=True` to reset the index to a clean `RangeIndex` after
stacking, preventing duplicate index labels.

```python
combined = pd.concat([df_jan, df_feb, df_mar], ignore_index=True)
```

### What is the difference between `map`, `apply`, and `DataFrame.map`?

- `Series.map(func)` — applies a function or lookup element-by-element on a single Series.
- `DataFrame.apply(func, axis=0|1)` — applies a function along an axis (column-wise or row-wise).
- `DataFrame.map(func)` (pandas 2.1+, formerly `applymap`) — applies element-by-element across an entire DataFrame.

Use `Series.map` for single-column lookups or value substitution, `apply` for
row or column-level logic, and `DataFrame.map` for element-wise
transformations across all cells.

def is_anagram(s, t):
    return Counter(s) == Counter(t)`,

## Concept check

<MultipleChoice
  markdown={`Sorting both strings (\`sorted(s) == sorted(t)\`) also works. Why is the \`Counter\` / hash-map approach usually preferred for large inputs?

- It uses less memory because it stores nothing.
  > It does store counts (O(k) for k distinct characters); its advantage is time, not zero memory.
- [o] Counting is O(n), while sorting both strings is O(n log n).
  > Building two frequency maps and comparing them is linear in the input length; sorting adds a log-n factor.
- Sorting gives the wrong answer for anagrams.
  > Sorting is correct — two strings are anagrams iff their sorted forms match. It's just asymptotically slower.
- The hash-map version is the only one that handles Unicode.
  > Both handle Unicode fine; the difference is time complexity.`}
/>

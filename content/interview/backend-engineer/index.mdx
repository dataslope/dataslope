Software engineering interviews center on **data structures and
algorithms**, **complexity analysis**, and **language fundamentals**,
usually in a live coding setting. Backend roles add API/system design and
database questions on top.

## What interviewers probe

- **Data structures**, arrays, hash maps, stacks/queues, trees, graphs, heaps.
- **Algorithms**, two pointers, sliding window, recursion, BFS/DFS, sorting, dynamic programming.
- **Complexity**, reasoning about time and space in Big-O, and improving a brute-force solution.
- **Language fundamentals**, idioms, the standard library, and gotchas in your chosen language.
- **(Backend)** API & system design, SQL, caching, concurrency.

## How AI has changed this interview

- **Two kinds of coding round.** AI-allowed rounds (Canva, Meta's AI-enabled round, a Google pilot) give you an assistant and grade how you drive and verify it. Others ban assistants, and Amazon and Anthropic can disqualify candidates who use one anyway. Google has also brought back an in-person round.
- **Reading and debugging over writing from scratch**: multi-file projects to extend, and code comprehension rounds on unfamiliar code.
- **Fewer take-homes**, which an assistant can complete unseen, and more live design discussion with "why?" follow-ups.
- **LLM features in system design**: streaming, retries, cost measured in tokens, and prompt injection.

[AI-assisted coding](/interview-prep/backend-engineer/ai-assisted-coding) covers these changes and how to prepare for both formats.

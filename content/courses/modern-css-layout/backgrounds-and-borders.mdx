The edge and surface of a box do a lot of the visual work: a border to
define it, a rounded corner to soften it, a background to fill it. This
lesson covers all three, plus `outline`, the border's layout-free cousin.

<Figure
  slug="css-backgrounds-borders-cutout"
  alt="A panel with a thick rounded frame and a filled surface, a second detached outline ring hovering just outside its edge"
/>

## Borders

The `border` shorthand takes a **width**, a **style**, and a **color**:

```css
border: 2px solid #6366f1;
```

The **style** is required, without it there is no border to see.
`border-radius` rounds the corners; two special values come up
constantly: **`50%`** turns a square into a circle, and a large value
like **`999px`** makes a **pill**.

<LivePreview
  title="Rounded card, circle, and pill"
  html={`<div class="row">

  <div class="avatar">AB</div>
  <div class="pill">pill button</div>
</div>`}
  css={`.row {
  display: flex;
  gap: 22px;
  align-items: center;
  flex-wrap: wrap;
  font-family: system-ui, sans-serif;
}
.rounded {
  padding: 18px;
  border: 2px solid #6366f1;
  border-radius: 14px;
  background: #eef2ff;
  color: #3730a3;
}

  width: 72px;
  height: 72px;
  border-radius: 50%;             /* square to circle */
  background: linear-gradient(135deg, #f472b6, #8b5cf6);
  color: white;
  font-weight: 700;
  display: flex;
  align-items: center;
  justify-content: center;

  padding: 8px 20px;

  background: #10b981;
  color: white;
  font-weight: 600;

/>

You can set each side on its own with `border-top`, `border-right`,
`border-bottom`, `border-left`, and switch the **style** between
`solid`, `dashed`, and `dotted`:

  border-bottom: 2px solid #cbd5e1;
}`}
/>

## Backgrounds

`background-color` fills the box. `background-image` layers an image on
top, and a **gradient counts as an image**, so it lives here too.

<Figure
  slug="css-backgrounds-and-borders-inline-cutout"
  alt="A panel with a patterned fill inside and a distinct framed edge drawn around it"
/>

Four properties control how that image sits:

- **`background-size`** sizes the image. `cover` fills the box (cropping
  as needed), `contain` fits the whole image inside, or give explicit
  lengths like `40px 40px`.
- **`background-position`** places it, e.g. `center` or `top right`.
- **`background-repeat`** tiles it; the default is `repeat`, or turn it
  off with `no-repeat`.
- The **`background` shorthand** packs them into one line.

Both tiles below use the same dot gradient; only `background-size`
differs, so the same pattern renders small on the left and large on the
right:

<LivePreview
  title="Same pattern, different background-size"
  html={`<div class="row">
  <div class="tile small">size: 20px</div>
  <div class="tile big">size: 40px</div>
</div>`}
  css={`.row {
  display: flex;
  gap: 16px;
  flex-wrap: wrap;
  font-family: system-ui, sans-serif;
}
.tile {
  flex: 1;
  min-width: 150px;
  height: 130px;
  border-radius: 12px;
  padding: 10px;
  color: #1e1b4b;
  font-weight: 600;
  background-color: #eef2ff;
  background-image: radial-gradient(circle, #6366f1 28%, transparent 30%);
}
.small { background-size: 20px 20px; }
.big   { background-size: 40px 40px; }`}
/>

The shorthand can carry the image, repeat, position, and size at once.
Here it is combining a gradient with `no-repeat center / cover`:

<LivePreview

  css={`.hero {

  justify-content: center;

  padding: 0 1rem;
  background: linear-gradient(135deg, #0ea5e9, #7c3aed) no-repeat center / cover;
}`}
/>

## `outline` vs `border`

`outline` looks like a border but has one crucial difference: it does
**not take up space**. A border is part of the box and pushes
everything around it; an outline is drawn on top, so adding or removing
it never shifts the layout. That is exactly why browsers use it for
focus rings.

<Figure
  slug="css-backgrounds-and-borders-borders-inline-cutout"
  alt="A panel with a distinct framed edge drawn around it, the frame's thickness visible at the corner"
/>

Notice how the **border** button below is visibly taller than its
neighbors (its 4px border grows the box), while the **outline** buttons
stay the same size as the plain one. `outline-offset` pushes the
outline away from the edge:

<LivePreview
  title="border grows the box, outline does not"
  background="#ffffff"
  html={`<div class="row">
  <button class="btn">plain</button>
  <button class="btn bordered">border</button>
  <button class="btn outlined">outline</button>
  <button class="btn offset">outline-offset</button>
</div>`}
  css={`.row {
  display: flex;
  gap: 18px;
  align-items: center;
  flex-wrap: wrap;
  font-family: system-ui, sans-serif;
}
.btn {
  padding: 10px 16px;
  border-radius: 8px;
  background: #6366f1;
  color: white;
  border: none;
  font-size: 14px;
}
.bordered { border: 4px solid #f59e0b; }
.outlined { outline: 4px solid #f59e0b; }
.offset   { outline: 4px solid #f59e0b; outline-offset: 6px; }`}
/>

`border-style`, tweak the `background`, and Run:

<Callout type="info" title="border-radius takes two radii">
A value like `border-radius: 40px / 20px` gives an ellipse per corner
(horizontal radius before the slash, vertical after). And you can round
just one corner with `border-top-left-radius`.
</Callout>

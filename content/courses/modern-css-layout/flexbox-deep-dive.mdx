Flexbox lays out items along **one axis**, a row or a column, and
gives you precise control over how they share space and align. It's the
right tool for navbars, toolbars, button groups, and anything
"a few things in a line."

<Figure
  slug="css-flexbox-cutout"
  alt="Four rounded blocks distributed along a single horizontal rail, one block stretching wider to absorb the leftover gap"
/>

## Two axes

`display: flex` creates a flex container whose children are **flex
items**. Everything flexbox does is described relative to two axes:

- The **main axis**, the direction items flow (`flex-direction: row`
  → horizontal; `column` → vertical).
- The **cross axis**, perpendicular to it.

<Figure
  slug="css-flexbox-deep-dive-two-axes-inline-cutout"
  alt="A rail with blocks spaced along it and a second rule crossing it at right angles"
  caption="Flexbox has a main axis and a cross axis, and every property names one of them."
/>

`justify-content` aligns along the **main** axis; `align-items` aligns
along the **cross** axis. Flip `flex-direction` and those two swap
meaning, which is the single most common source of "why is my
alignment on the wrong axis?"

| Property | Axis | Common values |
| --- | --- | --- |
| `justify-content` | main | `flex-start`, `center`, `space-between`, `space-around` |
| `align-items` | cross | `stretch`, `center`, `flex-start`, `baseline` |
| `align-self` | cross | override `align-items` for one item |

Each row below is the same three-item flex container with a different
`justify-content`. Reading them top to bottom is the fastest way to
build intuition for how the main-axis alignment spreads items:

on any row, or change `flex-direction` to `column`, and the main axis
swaps with it:

That `margin-right: auto` trick is worth memorizing: an `auto` margin
in a flex container absorbs all available space on that side, so one
item can shove its siblings to the far end.

## `flex`: grow, shrink, basis

Each item's `flex` shorthand is three values in a fixed order:

<SyntaxBreakdown
  parts={[
    { text: "flex:" },
    { text: "1", label: "grow, share of the leftover space" },
    { text: "1", label: "shrink, how readily it gives space back" },
    { text: "200px;", label: "basis, its size before either happens" },
  ]}
/>

Taken one at a time:

- **`flex-grow`**, how much of the *leftover* space this item takes
  (0 = don't grow).
- **`flex-shrink`**, how readily it shrinks when space is tight
  (1 = allowed to shrink).
- **`flex-basis`**, its starting size before grow/shrink.

<Figure
  slug="css-flexbox-deep-dive-inline-cutout"
  alt="A rail of blocks with springs between them, one block visibly wider because its own spring is stiffer than the rest"
  caption="`flex-grow` decides how the spare space is shared between the items."
/>

Read that first bullet carefully: `flex-grow` divides the *leftover*, not
the container, which is why three items with grow factors 1, 1 and 2 are
never in the ratio 1:1:2 at any width unless their bases are zero.

<Chart slug="flex-grow-distribution" />

The two you'll write most:

```css
.item { flex: 1; }      /* grow to share space equally: 1 1 0 */
.item { flex: none; }   /* don't grow or shrink: 0 0 auto */
```

<CodeBlock
  adapter="web"

    <link rel="stylesheet" href="styles.css" />
  </head>

      <div class="sidebar">Fixed 120px</div>

/>

## Wrapping

By default flex items stay on one line and shrink. `flex-wrap: wrap`
lets them flow onto new lines when they run out of room, the basis of
a responsive card row that needs no media query.

The row below wraps: each card has a `flex-basis` of `140px` and is
allowed to grow, so they fill the line and spill onto the next when the
container is too narrow. Resize your window and watch the rows reflow:

<LivePreview
  title="A self-wrapping card row, no media query"
  html={`<div class="cards">
  <div>Fast</div>
  <div>Secure</div>
  <div>Simple</div>
  <div>Open</div>
  <div>Scalable</div>
</div>`}
  css={`.cards {
  display: flex;
  flex-wrap: wrap;         /* let items flow onto new lines */
  gap: 10px;
}
.cards > div {
  flex: 1 1 140px;         /* grow, shrink, start at 140px */
  padding: 20px;
  text-align: center;
  font-weight: 700;
  background: #dcfce7;
  color: #166534;
  border-radius: 10px;
  font-family: system-ui, sans-serif;
}`}
/>

Flexbox owns one dimension. For rows *and* columns together, you want
[CSS Grid](/courses/modern-css-layout/css-grid).

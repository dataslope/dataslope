Every element on a page is a rectangular **box**. Layout is the art of
sizing and spacing those boxes, and it all starts with the four layers
of the box model.

<Figure
  slug="css-box-model-cutout"
  alt="A single box shown as four concentric nested frames on a platform, each ring a different brand colour, the innermost holding a solid block"
/>

## The four layers

From the inside out:

1. **Content**, the text or image itself.
2. **Padding**, space *inside* the box, between content and border.
   Shares the background.
3. **Border**, a line around the padding.
4. **Margin**, space *outside* the box, pushing other boxes away.
   Always transparent.

<Figure
  slug="css-box-model-and-sizing-inline-cutout"
  alt="Two identical blocks measured by a rule, one measured to its content only and one measured to its outer edge, giving different totals"
/>

```text
┌─────────── margin ───────────┐
│  ┌──────── border ────────┐  │
│  │  ┌───── padding ────┐  │  │
│  │  │     content      │  │  │
│  │  └──────────────────┘  │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

The same four layers, rendered for real. The tinted area is padding
(it shares the box's background), the solid line is the border, and
the space *between* the two boxes is margin:

## `box-sizing`: the one setting everyone changes

By default (`box-sizing: content-box`), `width` sets the **content**
width, and padding and border are *added on top*. So
`width: 200px; padding: 20px; border: 2px` actually occupies **244px**.
That surprises everyone and makes layouts hard to reason about.

The fix is universal:

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

Now `width` means the **total** width including padding and border. Set
`width: 200px` and the box is 200px, full stop. Nearly every real
project puts this rule at the top of its stylesheet.

Both boxes below ask for `width: 220px` and add `24px` of padding. The
first uses `content-box` (the default) and overflows to 268px; the
second uses `border-box` and stays exactly 220px. The gridlines are
`20px` apart so you can measure the difference:

## Spacing gotchas

- **Vertical margins collapse.** Two stacked boxes with `32px` and
  `16px` vertical margins end up `32px` apart, not `48px`, the larger
  one wins. This only happens vertically, and it's why many teams use
  `gap` (flex/grid) or one-directional margins instead.
- **`margin: 0 auto`** horizontally centers a block that has a set
  width, the classic centered container.

Before you reach for flexbox or grid, it pays to understand the layout
you already have for free: **normal flow**. Every element is a box, and
the `display` property decides how that box behaves in the flow, whether
it stacks, sits in a line, or steps out entirely.

## Normal flow: block vs inline

By default, boxes come in two flavors. A **block** box (like `<div>`,
`<p>`, `<h1>`) starts on a new line and fills the full width available,
so blocks stack vertically. An **inline** box (like `<span>`, `<a>`,
`<strong>`) sits in the running text and takes only the width of its
content, so inline boxes flow left to right and wrap like words.

## The display property

`display` lets you change a box's flow behavior. The four classic
values:

- `block`, starts a new line, fills the width.
- `inline`, flows in a line, sizes to content. **Width and height are
  ignored, and top/bottom padding and margin do not push the surrounding
  lines apart.**
- `inline-block`, the best of both: it sits in a line like inline text,
  but it respects `width`, `height`, and padding like a block.
- `none`, removes the box from the flow entirely, as if it were never
  in the document.

### inline vs inline-block

Both spans below ask for `width: 140px` and `padding: 14px`. The plain
`inline` one ignores the width and lets its vertical padding overlap
neighbors instead of reserving space. The `inline-block` one honors
every value:

<LivePreview
  height={98}
  title="inline ignores width and vertical spacing; inline-block respects both"
  background="#ffffff"
  html={`<span class="tag as-inline">inline</span>

  css={`.tag {

  font-family: system-ui, sans-serif;
}

.as-inline-block { display: inline-block; }`}
/>

### none vs visibility: hidden

`display: none` pulls the element out of the flow, so the space it
occupied collapses. That is different from `visibility: hidden`, which
hides the element but **keeps its space reserved**. Watch what happens
to box 2 in each row:

<LivePreview
  height={152}
  title="display:none collapses the gap; visibility:hidden keeps it"
  background="#ffffff"
  html={`<div class="row">
  <div class="box">1</div>
  <div class="box gone">2</div>
  <div class="box">3</div>
</div>
<div class="row">
  <div class="box">1</div>
  <div class="box invisible">2</div>
  <div class="box">3</div>
</div>`}
  css={`.row { margin-bottom: 12px; }
.box {
  display: inline-block;
  width: 44px;
  height: 44px;
  margin-right: 8px;
  background: #14b8a6;
  color: white;
  font-weight: 700;
  text-align: center;
  line-height: 44px;
  font-family: system-ui, sans-serif;
}
.gone { display: none; }
.invisible { visibility: hidden; }`}
/>

In the first row, box 3 slides left to fill the gap. In the second, the
hidden box still holds its place.

## flex and grid are display values too

The layout engines you will meet next are also `display` values. Setting
`display: flex` or `display: grid` on a container switches its children
into a whole new flow model:

```css
.toolbar { display: flex; }   /* lay children out in a flexible row */
.gallery { display: grid; }   /* place children on a grid */
```

Those get full lessons of their own, but it is worth seeing that they
sit on the same property you have been using all along.

<Callout type="info" title="display: none hides from assistive tech too">
Because `display: none` removes the box from the document, screen
readers skip it entirely. That is usually what you want for truly
inactive content, but if you only mean to hide something visually while
keeping it announced, reach for other techniques instead of `none`.
</Callout>

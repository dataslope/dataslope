Color is the fastest way to make a page feel intentional. This lesson
covers the notations CSS gives you for naming a color, the gradients
that blend between colors, and the shadows that lift elements off the
page.

## Naming a color

CSS accepts the same color in several notations. These four all produce
the **exact same blue**:

```css
color: royalblue;          /* named    */
color: #4169e1;            /* hex      */
color: rgb(65 105 225);    /* rgb()    */
color: hsl(225 73% 57%);   /* hsl()    */
```

- **Named** colors (`tomato`, `rebeccapurple`) are handy but fixed.
- **Hex** is `#rrggbb`, two hex digits each for red, green, blue. The
  short `#rgb` form doubles each digit, so `#4af` means `#44aaff`.
- **`rgb()`** takes the channels as numbers, 0 to 255.
- **`hsl()`** is **hue** (0–360 around the color wheel), **saturation**,
  and **lightness**. It is the friendliest to tweak by hand: nudge the
  lightness for a hover state, or spin the hue to re-theme, without
  guessing at hex digits.

### Alpha: making a color translucent

Add an alpha channel to let the background show through. The modern
syntax puts the alpha after a slash: `rgb(59 130 246 / 0.5)` or
`hsl(225 73% 57% / 0.5)` is half-transparent. Hex has a four-digit
`#rgba` short form and an eight-digit `#rrggbbaa` form too.

Where translucent circles overlap, their colors mix and the shared area
darkens, that is the alpha at work:

## Gradients

A gradient is an **image** you build from color stops, so it goes
wherever an image can, most often `background`.

- **`linear-gradient(135deg, a, b)`** blends along a line. The angle
  points the line: `0deg` is up, `90deg` is right, `135deg` runs to the
  bottom-right.
- Add more stops for a **multi-stop** blend, and pin a stop to a
  position: `linear-gradient(90deg, green, gold 50%, red)`.
- **`radial-gradient(...)`** blends outward from a point in rings.

## Shadows

`box-shadow` casts a shadow shaped like the element's box. The values,
in order, are **x-offset**, **y-offset**, **blur**, **spread**, and
**color**:

```css
box-shadow: 0 10px 25px rgba(15, 23, 42, 0.18);
```

- Larger **blur** makes a softer, more diffuse shadow; **spread** grows
  or shrinks its size.
- The `inset` keyword draws the shadow **inside** the box, for a pressed
  or recessed look.
- Comma-separate several shadows to **layer** them. A stack of faint
  shadows reads as far more realistic depth than one heavy shadow.

### `text-shadow`

Text gets its own shadow property with the same x, y, blur, color
values, no spread. A subtle offset adds depth; a blurred copy in the
text color reads as a glow:

<LivePreview
  title="text-shadow"
  background="#ffffff"

  css={`.title {
  font-family: system-ui, sans-serif;
  font-size: 34px;
  color: #6d28d9;
  text-shadow: 2px 3px 0 rgba(109, 40, 217, 0.25);
}`}
/>

<Callout type="info" title="HSL makes states easy">
Because lightness is its own number, a hover color is often just the
same `hsl()` with the lightness dropped a few points, no new hex to
pick. That is why design systems lean on HSL for tints and shades.
</Callout>

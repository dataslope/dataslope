Welcome to **Modern CSS: Layout & Responsive Design**. CSS has a
reputation for being fiddly, mostly because people learn its
properties without learning the *systems* behind them: how rules
combine, how boxes size themselves, how layout engines place things.
This course teaches those systems, and every rule you write renders
instantly next to it.

## How this course works

Each lesson mixes two kinds of hands-on:

1. **Live previews** that render the moment the page loads, no button
   to press. The rendered result sits on top and the exact HTML and CSS
   that produced it sit right below, so you can read cause and effect at
   a glance. Here's one now:

<LivePreview
  height={88}
  title="A live preview, rendered with no Run button"
  background="#ffffff"
  html={`<div class="chip">CSS you can see</div>`}
  css={`.chip {
  display: inline-block;
  padding: 10px 18px;
  border-radius: 999px;
  font-family: system-ui, sans-serif;
  font-weight: 700;
  color: white;
  background: linear-gradient(135deg, #6366f1, #ec4899);
}`}
/>

2. **Editable code blocks** you run yourself. These compose your HTML
   and CSS into a sandboxed page and render it under the editor. Change
   a value, press **Run** (or Ctrl/Cmd + Enter), and see the layout
   react.

<CodeBlock
  adapter="web"
  entryFilename="index.html"
  files={[
    {
      filename: "index.html",
      starterCode: `<!DOCTYPE html>
<html>
  <head>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <div class="hero">
      <h1>CSS you can see</h1>
      <p>Change a value in styles.css and press Run.</p>
    </div>
  </body>
</html>
`,
    },
    {
      filename: "styles.css",
      starterCode: `body {
  margin: 0;
  font-family: system-ui, sans-serif;
}

.hero {
  display: grid;
  place-items: center;
  height: 60vh;
  text-align: center;
  color: white;
  background: linear-gradient(135deg, #6366f1, #ec4899);
}

.hero h1 {
  font-size: clamp(2rem, 6vw, 4rem);
  margin: 0;
}
`,
    },
  ]}
/>

Try changing the two gradient colors, or the `135deg` angle, and Run.
That single `clamp()` on the heading is already responsive, it scales
with the viewport between a floor and a ceiling.

## What you'll learn

1. **The cascade and specificity**, why one rule wins over another.
2. **Selectors and combinators**, targeting exactly the elements you
   mean.
3. **The box model, `display`, and `box-sizing`**, how every element
   sizes itself and joins the flow.
4. **Flexbox**, one-dimensional layout, in depth.
5. **CSS Grid**, two-dimensional layout, in depth.
6. **Positioning and stacking**, taking elements out of the flow.
7. **Color, backgrounds, and pseudo-elements**, the layer that makes a
   page look designed rather than merely arranged.
8. **Responsive design and container queries**, fluid units, media
   queries, mobile-first, and components that respond to their own
   width.
9. **Custom properties**, variables, theming, and dark mode.
10. **Transforms, transitions, and animations**, motion that feels
    intentional.
11. **The modern toolbox**, `aspect-ratio`, native nesting, `:has()`,
    logical properties, and `clamp()`.
12. **A responsive landing page** that puts it all together.

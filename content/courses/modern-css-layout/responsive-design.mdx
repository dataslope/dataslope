A responsive layout isn't a separate "mobile site", it's *one* layout
that adapts. The craft has two halves: make things **fluid** by
default, and **change the layout** at breakpoints where fluid alone
isn't enough.

## Fluid by default

Before any media query, prefer units that flex with the viewport:

- **`%` / `fr` / `auto`** so boxes share available space.
- **`max-width`** to cap a container on big screens without forcing a
  width on small ones: `width: 100%; max-width: 60rem;`.
- **`rem`** for type, so everything scales from one root size.
- **`min()`, `max()`, `clamp()`** for values that adapt within limits.

`clamp(min, preferred, max)` is the star: a value that grows with the
screen but never past a floor or ceiling. One line replaces several
font-size media queries:

Slowly resize your browser and watch the heading below. It scales
smoothly with the viewport (`4vw`) but never shrinks below `1.25rem` or
grows past `2.5rem`, all from one declaration:

## Media queries: change the layout

When a layout needs to *restructure*, not just resize, a **media
query** applies rules only when a condition holds:

```css
@media (min-width: 640px) {
  .grid { grid-template-columns: 1fr 1fr; }
}
```

The width you switch at is a **breakpoint**. Choose breakpoints where
*your content* breaks, not by chasing specific device sizes.

## Mobile-first

Write the **small-screen** layout as the base with no query, then add
complexity for wider screens using `min-width`:

```css
.cards { grid-template-columns: 1fr; }          /* phones: one column */

@media (min-width: 640px) {
  .cards { grid-template-columns: 1fr 1fr; }     /* tablets: two */
}
@media (min-width: 960px) {
  .cards { grid-template-columns: repeat(3, 1fr); } /* desktop: three */
}
```

This tends to produce simpler CSS: the base case is the most
constrained, and each query only *adds*. It also means the smallest,
often slowest, devices get the least CSS to process.

<Callout type="info" title="Don't forget the viewport meta tag">
Responsive CSS does nothing without `<meta name="viewport"
content="width=device-width, initial-scale=1" />` in the `<head>`.
Without it, phones render the page at desktop width and shrink it,
your media queries never trigger.
</Callout>

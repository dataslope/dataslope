Grid is CSS's two-dimensional layout system: you define **columns and
rows** on a container, and place children into the resulting cells.
Where flexbox flows items along a line, grid gives you a coordinate
system.

## Defining tracks

Two properties set up the grid, plus `gap` for the gutters:

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* three columns */
  grid-template-rows: auto 200px;      /* two rows */
  gap: 1rem;
}
```

The **`fr`** unit means "a fraction of the free space." `repeat(3, 1fr)`
is shorthand for three equal columns; `2fr 1fr` makes the first twice
the width of the second.

## Placing and spanning items

By default items fill cells in order, but any item can span multiple
tracks with `grid-column` / `grid-row`. `span 2` means "cover two
columns"; `1 / -1` means "from the first line to the last", full width:

<CodeBlock
  adapter="web"
  entryFilename="index.html"
  files={[
    {
      filename: "index.html",
      starterCode: `<!DOCTYPE html>
<html>
  <head>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <div class="layout">
      <header>Header (spans all columns)</header>
      <aside>Sidebar</aside>
      <main>Main content (spans two columns)</main>
    </div>
  </body>
</html>
`,
    },
    {
      filename: "styles.css",
      starterCode: `body {
  font-family: system-ui, sans-serif;
  margin: 1.5rem;
}

.layout {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

.layout > * {
  padding: 1rem;
  border-radius: 10px;
}

header {
  grid-column: 1 / -1; /* first line to last: full width */
  background: #1e293b;
  color: white;
}
aside {
  background: #e2e8f0;
}
main {
  grid-column: span 2; /* cover two columns */
  background: #dbeafe;
}
`,
    },
  ]}
/>

## Named areas: layout as a picture

For page-level layouts, `grid-template-areas` lets you *draw* the
layout as text, then assign each element to a named area. It's the most
readable way to express a classic header/sidebar/content/footer shell,
and rearranging it in a media query is a one-line change.

Each quoted string is one row, and each word in it is one column. Repeat
a name across cells and that area spans them, so the picture in the CSS
has the same shape as the layout on screen:

```css
grid-template-areas:
  "header  header"
  "sidebar main"
  "footer  footer";
```

Then every child says which area it belongs to with `grid-area`, and
the order of the elements in the HTML no longer matters:

<LivePreview
  title="A page shell drawn as text"
  html={`<div class="page">
  <header>header</header>
  <aside>sidebar</aside>
  <main>main</main>
  <footer>footer</footer>
</div>`}
  css={`.page {
  display: grid;
  grid-template-columns: 120px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 10px;
  font-family: system-ui, sans-serif;
}
header { grid-area: header; background: #1e293b; color: white; }
aside  { grid-area: sidebar; background: #e2e8f0; }
main   { grid-area: main; background: #dbeafe; min-height: 90px; }
footer { grid-area: footer; background: #f1f5f9; }
.page > * {
  padding: 12px;
  border-radius: 8px;
  font-weight: 600;
}`}
/>

To move the sidebar to the right, flip that row to `"main sidebar"` and
the tracks to `1fr 120px`. No element moves in the HTML, and nothing
else in the stylesheet changes.

## Responsive with no media query

The single most useful grid line for responsive galleries:

```css
grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
```

"Fit as many columns as possible, each at least `180px`, sharing
leftover space equally." Resize and the column count changes on its
own. Reach for a media query only when the layout must *change shape*,
not merely reflow.

This gallery uses exactly that one line. Drag your browser wider and
narrower: the tiles re-flow from one column to two, three, or more,
with no breakpoints anywhere in the CSS:

<LivePreview
  title="A responsive gallery from a single line of CSS"
  html={`<div class="gallery">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>`}
  css={`.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
  gap: 10px;
  font-family: system-ui, sans-serif;
}
.gallery > div {
  aspect-ratio: 4 / 3;
  display: grid;
  place-items: center;
  font-size: 1.4rem;
  font-weight: 700;
  color: white;
  background: linear-gradient(135deg, #6366f1, #ec4899);
  border-radius: 10px;
}`}
/>

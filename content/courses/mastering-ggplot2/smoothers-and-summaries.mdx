Some layers do not show your data at all, they show a **computation
over** your data: a trend line, a group average, a confidence band.
These statistical layers are how ggplot2 turns a cloud of points into
an argument.

## geom_smooth: a trend made visible

`geom_smooth()` fits a model to the data and draws the fitted curve
plus a confidence band. Its stat does real statistical work, then hands
a smooth curve to the geom.

<Figure
  slug="gg-smoothers-and-summaries-geom-smooth-trend-inline-cutout"
  alt="A cloud of chips with a soft ribbon drawn through their middle and a band either side"
  caption="The smoother fits a model and draws its fit with a confidence band."
/>

<CodeBlock
  adapter="r"
  files={[
    {
      filename: "main.r",
      starterCode: `library(ggplot2)

ggplot(mpg, aes(displ, hwy)) +
  geom_point(alpha = 0.5) +
  geom_smooth()
`,
    },
  ]}
/>

By default it uses a flexible **loess** curve (for smaller data) that
bends to follow local structure. The grey ribbon is the **confidence
interval**, the stat computed it for you.

## Choosing the model with `method`

The same geom can fit different models. `method = "lm"` fits a straight
line (linear model); the default follows the data's curves:

<CodeBlock
  adapter="r"
  files={[
    {
      filename: "main.r",
      starterCode: `library(ggplot2)

# A straight-line fit: assumes a linear relationship.
ggplot(mpg, aes(displ, hwy)) +
  geom_point(alpha = 0.5) +
  geom_smooth(method = "lm", color = "darkred")
`,
    },
  ]}
/>

**Raw points `(displ, hwy)` → `stat_smooth()` fits a model (`lm` or
`loess`) → fitted values + a confidence band → `geom_smooth()` draws the
line + ribbon.**

Switching `method` swaps the *statistic's* model while the *geom*
(line + ribbon) stays the same, yet another instance of separating
computation from drawing.

<Callout type="warn" title="A smoother is a claim, not a fact">
A straight `lm` line *assumes* the relationship is linear; a loess
curve assumes it is locally smooth. Neither is "the truth", each is a
model. Always show the raw points alongside a smoother so readers can
judge whether the model fits.
</Callout>

## stat_summary: summarize per group, your way

When you want a custom summary, say, the **mean** of y for each x
category with error bars, `stat_summary()` computes it on the fly
without you pre-aggregating the data:

<CodeBlock
  adapter="r"
  files={[
    {
      filename: "main.r",
      starterCode: `library(ggplot2)

# Mean highway MPG per class, computed at plot time, drawn as points.
ggplot(mpg, aes(class, hwy)) +
  geom_jitter(width = 0.15, alpha = 0.3) +
  stat_summary(
    fun = mean, geom = "point",
    color = "red", size = 4
  )
`,
    },
  ]}
/>

The red dots are *not* in your data, `stat_summary` computed the mean
per class and the `point` geom drew them on top of the raw (jittered)
values. Notice `geom =` *inside* a stat: confirming again that stats
and geoms are interchangeable partners.

You can add a range too:

<CodeBlock
  adapter="r"
  files={[
    {
      filename: "main.r",
      starterCode: `library(ggplot2)

# Mean with a min-max range bar per class.
ggplot(mpg, aes(class, hwy)) +
  stat_summary(
    fun = mean,
    fun.min = min, fun.max = max,
    geom = "pointrange", color = "steelblue"
  )
`,
    },
  ]}
/>

## Raw data + summary: the honest pattern

The most trustworthy statistical graphics show **both** the raw data
and the summary, so the reader sees the evidence *and* the claim. Four
groups whose summary is identical and whose data is not:

produce the same regression, and only one of them should have one.

<CodeBlock
  adapter="r"
  files={[
    {
      filename: "main.r",
      starterCode: `library(ggplot2)

ggplot(mpg, aes(displ, hwy)) +
  geom_point(alpha = 0.4) + # the evidence
  geom_smooth(method = "lm", se = TRUE) + # the claim + uncertainty
  labs(title = "Bigger engines tend to use more fuel")
`,
    },
  ]}
/>

This layered honesty is something the grammar makes *natural*: the raw
layer and the summary layer are just two geoms stacked with `+`.

## Key takeaways

- Statistical layers show a **computation over** the data, not the raw
  data: trends, means, intervals.
- `geom_smooth()` fits a model (default loess, or `method = "lm"` for a
  line) and draws it with a confidence band.
- `stat_summary()` computes a custom per-group summary (e.g. `mean`) at
  plot time and renders it through a chosen geom.
- A smoother is a **model**, i.e. a claim, pair it with the raw data
  so readers can judge the fit.

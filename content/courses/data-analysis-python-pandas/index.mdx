Welcome to **Data Analysis with Python Pandas**. If you have never
written a line of code, never touched a Jupyter notebook, and only
know spreadsheets as "that thing accountants use", you are in the
right place.

This course is not a syntax reference. It is a guided tour through
how humans went from scratching tally marks on bones to running
multi-million-row analyses on a laptop, and how a small Python
library called **Pandas** became the lingua franca of modern data
work.

<Callout type="info" title="No setup required">

the output appear underneath the editor.
</Callout>

## Try it right now

Here is the surprising part: **this whole course runs in your
browser.** The block below is real Python with real data, 344
penguins measured in Antarctica. Click *Run* and watch the average
body mass of each species appear underneath.

That single line is a real analysis: it split 344 penguins into
three species, then averaged the body mass of each group. You will
spend several chapters learning to read and write lines exactly
like it.

Now make it your own. Change `"body_mass_g"` to
`"flipper_length_mm"` and run again, you have just measured each
species by a different attribute. Change `"species"` to `"island"`
and you are grouping by *where* the penguins live instead of
*what* they are. Nothing broke, nothing had to be reinstalled, and
you did not leave this page. That is the loop the rest of the
course lives inside: ask a question, change a line, run, look.

## Who this course is for

You will fit right in if any of these sound like you:

- You have heard people say "data analysis" but you are not sure
  what an analyst actually *does* day-to-day.
- You can sum a column in Excel, but the moment a dataset has fifty
  thousand rows and a few missing values, the spreadsheet falls
  apart.
- You have tried to read a Python tutorial and bounced off `pip`,
  `venv`, and `lambda` in the first five minutes.
- You are curious about data jobs, analyst, data scientist,
  researcher, product analyst, and you want to understand the
  ground floor before you start climbing.

You do **not** need:

- Any prior Python (or any programming) experience.
- A statistics background.
- A math background beyond grade-school arithmetic.
- A computer with anything installed.

## What you will learn

By the end of the course you will be able to:

- Open a real-world dataset and confidently describe what is in it.
- Clean missing values, fix inconsistent text, and handle bad rows.
- Slice, filter, sort, and rank data to answer specific questions.
- Group data and compute summaries the way a working analyst does.
- Combine multiple datasets into one with merges and joins.
- Reshape data between wide and long formats.
- Build simple but informative visualizations.
- Write analysis code that another person (or future you) can read
  and trust.

## How the course is organized

We open with **a short story**, where tabular data came from, why
spreadsheets ran the business world for thirty years, and why a
hedge-fund researcher named Wes McKinney built the library that
became Pandas. It is two pages, not a lecture, and you are running
analysis code within the first few chapters.

From there each chapter builds on the previous one. By the time we
reach GroupBy and merges, you will already understand the questions
those tools were designed to answer. (A few longer digressions,
the deep history, the famous spreadsheet disasters, wait for you
in an **Interesting discussions** section near the end, once you
have the context to enjoy them.)

## The datasets you will work with

This course uses a small cast of real, public datasets so you can
get to know them well rather than meeting a new file every page:

- **Palmer Penguins**, 344 penguins with their species, island,
  body measurements, and sex. Friendly, small, and (importantly)
  with a few genuinely missing values, so it is perfect for
  learning to clean data. You just used it.
- **Diamonds**, 53,940 diamonds with their cut, color, clarity,
  and price. When we need *scale* and rich categories, for
  grouping, pivoting, and "what does this look like at 50,000
  rows?", this is the one.
- **California Housing**, about 20,640 California districts, all
  numeric, ideal for summary statistics and correlations.

By the end of the course you will be slicing these by category,
comparing groups, flagging unusual rows, and building charts that
explain what you found, all in code you can re-run tomorrow on a
new file without changing the logic.

## A note on philosophy

Most "learn Pandas" material is a wall of method names and shapes.
This course is different. We care more about **why** an operation
exists than about memorizing its arguments. The reason is simple:
syntax is googlable, but *judgment*, knowing when to filter
before grouping, when to keep raw versus cleaned data, when a
median tells you more than a mean, is not. We will spend a lot of
time on judgment.

A component that always renders the same thing isn't very useful.
**Props** (short for "properties") are the inputs you pass to a
component, like arguments to a function, so the same component can
render different things.

## Passing and receiving props

You pass props as attributes, and receive them as a single object
parameter. With TypeScript you describe that object's shape:

<CodeBlock
  adapter="react"
  files={[
    {
      filename: "main.tsx",
      starterCode: `import { createRoot } from "react-dom/client";

function Greeting({ name }: { name: string }) {
  return <p>Hello, {name}!</p>;
}

function App() {
  return (
    <main style={{ fontFamily: "system-ui", margin: 24 }}>
      <Greeting name="Ada" />
      <Greeting name="Grace" />
      <Greeting name="Linus" />
    </main>
  );
}

createRoot(document.getElementById("root")!).render(<App />);
`,
    },
  ]}
/>

One component, three outputs, the difference is entirely in the props.
The `{ name }: { name: string }` is **destructuring** the props object
plus a TypeScript type saying "`name` is a string". Pass the wrong
type and the compiler complains before you ever Run.

Same idea, rendered live: one `Avatar` component, three different
`name` / `color` props, three different circles:

<ReactPreview
  code={`function Avatar({ name, color }: { name: string; color: string }) {
  return (
    <div className="avatar" style={{ background: color }}>
      {name.charAt(0)}
    </div>
  );
}

function Row() {
  return (
    <>
      <Avatar name="Grace" color="#4f46e5" />
      <Avatar name="Linus" color="#0891b2" />
      <Avatar name="Ada" color="#db2777" />
    </>
  );
}`}

## Props can be any type

Strings use quotes; everything else, numbers, booleans, arrays,
objects, functions, goes inside braces:

<CodeBlock
  adapter="react"
  files={[
    {
      filename: "main.tsx",
      starterCode: `import { createRoot } from "react-dom/client";

interface ProductProps {
  name: string;
  price: number;
  inStock: boolean;
  tags: string[];
}

function Product({ name, price, inStock, tags }: ProductProps) {
  return (
    <div style={{ fontFamily: "system-ui", margin: 24 }}>
      <h2>
        {name}, {"$"}
        {price.toFixed(2)}
      </h2>
      <p>{inStock ? "In stock" : "Sold out"}</p>
      <p>Tags: {tags.join(", ")}</p>
    </div>
  );
}

createRoot(document.getElementById("root")!).render(
  <Product
    name="Camp Mug"
    price={12.5}
    inStock={true}
    tags={["kitchen", "outdoors"]}
  />,
);
`,
    },
  ]}
/>

## Props are read-only

A component must **never** modify its own props. Props flow *down* from
the parent; a child that reassigned them would break React's one-way
data flow (and React would ignore the change anyway). If a value needs
to change over time, that's **state**, the next topic. Props are for
data a component *receives*; state is for data a component *owns*.

<Figure
  slug="rx-props-props-read-only-inline-cutout"
  alt="A tray handed down from a shelf above, the receiving hands able to read what is on it but not to move anything"
  caption="A child may read its props and never write them, which is what keeps the flow one-way."
/>

<Callout type="info" title="Default values">
Give a prop a default with normal JavaScript defaults during
destructuring: `function Badge({ tone = "info" }: { tone?: string })`.
The `?` marks the prop optional in the type.
</Callout>

The `Badge` below takes an optional `tone` prop. The first badge passes
nothing and falls back to the default; the others pass a tone to pick
their color, all from one small, reusable component:

<ReactPreview
  code={`function Badge({ children, tone = "indigo" }: {
  children: React.ReactNode;
  tone?: "indigo" | "green" | "amber" | "rose";
}) {
  const colors = {
    indigo: "#eef2ff", green: "#dcfce7",
    amber: "#fef3c7", rose: "#ffe4e6",
  };
  return <span style={{ background: colors[tone] }}>{children}</span>;
}

function Badges() {
  return (
    <>
      <Badge>Default</Badge>
      <Badge tone="green">Shipped</Badge>
      <Badge tone="amber">Pending</Badge>
      <Badge tone="rose">Blocked</Badge>
    </>
  );
}`}
>

</ReactPreview>

function Avatar(/* add typed props here */) {

    <div className="avatar">
      <div className="circle">??</div>
      <span>Name</span>
    </div>
  );
}

function App() {
  return (
    <main style={{ fontFamily: "system-ui", margin: 24 }}>
      <Avatar name="Ada Lovelace" initials="AL" />
      <Avatar name="Grace Hopper" initials="GH" />
    </main>
  );
}

createRoot(document.getElementById("root")!).render(<App />);
`,
      solutionCode: `import { createRoot } from "react-dom/client";
import "./styles.css";

function Avatar({ name, initials }: { name: string; initials: string }) {
  return (
    <div className="avatar">
      <div className="circle">{initials}</div>
      <span>{name}</span>
    </div>
  );
}

function App() {
  return (
    <main style={{ fontFamily: "system-ui", margin: 24 }}>
      <Avatar name="Ada Lovelace" initials="AL" />
      <Avatar name="Grace Hopper" initials="GH" />
    </main>
  );
}

createRoot(document.getElementById("root")!).render(<App />);
`,
    },
    {
      filename: "styles.css",
      starterCode: `.avatar {
  display: flex;
  align-items: center;
  gap: 0.5rem;
  margin: 0.5rem 0;
}
.circle {
  width: 40px;
  height: 40px;
  border-radius: 999px;
  background: #dbeafe;
  color: #1d4ed8;
  font-weight: 700;
  display: grid;
  place-items: center;
}
`,
    },
  ]}

if (circles.length !== 2) {

    {
      id: "initials",

for (const expected of ["AL", "GH"]) {

      name: "Each avatar shows its name",

for (const name of ["Ada Lovelace", "Grace Hopper"]) {
  if (!text.includes(name)) throw new Error("Missing name: '" + name + "'.");
}`,

React elements accept event handlers as props: `onClick`,
`onChange`, `onSubmit`, `onMouseEnter`, and so on. You hand them a
**function**, and React calls it when the event fires.

<Figure
  slug="rx-events-cutout"
  alt="A button block on a panel with a coiled trigger line running to a small waiting mechanism beside it"
/>

## Handlers are functions you pass, not call

```tsx
<button onClick={handleClick}>Go</button>   // ✅ pass the function
<button onClick={handleClick()}>Go</button>  // ❌ calls it during render
```

The second line runs `handleClick` immediately while rendering and
passes its *return value* as the handler, a very common early
mistake. When you need to pass arguments, wrap it in an arrow function
so the call is deferred until the click:

<CodeBlock
  adapter="react"
  files={[
    {
      filename: "main.tsx",
      starterCode: `import { useState } from "react";
import { createRoot } from "react-dom/client";

function Palette() {
  const [color, setColor] = useState("white");
  const colors = ["tomato", "gold", "mediumseagreen", "cornflowerblue"];

  return (
    <main style={{ fontFamily: "system-ui", margin: 24 }}>
      <div style={{ display: "flex", gap: 8, marginBottom: 12 }}>
        {colors.map((c) => (
          // arrow function defers the call until the click
          <button key={c} onClick={() => setColor(c)}>
            {c}
          </button>
        ))}
      </div>
      <div style={{ height: 80, borderRadius: 10, background: color }} />
      <p>Selected: {color}</p>
    </main>
  );
}

createRoot(document.getElementById("root")!).render(<Palette />);
`,
    },
  ]}
/>

A single handler can do several things. The like button below flips a
boolean *and* adjusts a count on each click, all inside one `onClick`:

<ReactPreview
  code={`function LikeButton() {
  const [likes, setLikes] = useState(0);
  const [liked, setLiked] = useState(false);

  function toggle() {
    setLiked(!liked);
    setLikes((n) => n + (liked ? -1 : 1));
  }

  return (
    <button onClick={toggle}>
      {liked ? "♥" : "♡"} {likes} {likes === 1 ? "like" : "likes"}
    </button>
  );
}`}

## The event object

Handlers receive an **event** object with details about what happened,
and methods like `preventDefault()`. For inputs, `event.target.value`
is the current text:

```tsx
<input onChange={(event) => console.log(event.target.value)} />
```

The `onKeyDown` handler below reads `event.key` off the event object on
every keystroke, type in the box and watch it report the last key and a
running count:

<ReactPreview
  code={`function KeyWatcher() {
  const [last, setLast] = useState("none");
  const [count, setCount] = useState(0);

  return (
    <div>
      <input
        placeholder="Type here…"
        onKeyDown={(event) => {
          setLast(event.key);
          setCount((n) => n + 1);
        }}
      />
      <p>Last key: <strong>{last}</strong> · {count} keystrokes</p>
    </div>
  );
}`}
>
  <KeyPressDemo />
</ReactPreview>

## Lifting state up

When two components need to share state, put the state in their
**closest common parent** and pass it down: the value as a prop, and a
setter (or a callback) as another prop. The child reports events *up*
by calling the callback; the parent owns the truth. This is the
standard way sibling components stay in sync.

<Figure
  slug="rx-handling-events-inline-cutout"
  alt="A button on a panel being pressed and a short cord carrying the press to a small handler box behind it"
  caption="An event handler is a prop, and React wires it to the element for you."
/>

<CodeBlock
  adapter="react"
  files={[
    {
      filename: "main.tsx",
      starterCode: `import { useState } from "react";
import { createRoot } from "react-dom/client";

// Child reports clicks up via the onVote callback prop.
function VoteButton({ label, onVote }: { label: string; onVote: () => void }) {
  return <button onClick={onVote}>{label}</button>;
}

// Parent owns the counts.
function Poll() {
  const [up, setUp] = useState(0);
  const [down, setDown] = useState(0);
  return (
    <main style={{ fontFamily: "system-ui", margin: 24 }}>
      <h1>
        👍 {up} · 👎 {down}
      </h1>
      <VoteButton label="Upvote" onVote={() => setUp(up + 1)} />{" "}
      <VoteButton label="Downvote" onVote={() => setDown(down + 1)} />
    </main>
  );
}

createRoot(document.getElementById("root")!).render(<Poll />);
`,
    },
  ]}
/>

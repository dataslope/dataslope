A React app is a tree of **components**. A component is just a
function that returns markup. That's the whole definition, everything
else builds on it.

```tsx
function Welcome() {
  return <h1>Hello from a component!</h1>;
}
```

Use it like an HTML element, with a capitalized name:

```tsx
<Welcome />
```

<Callout type="info" title="Capitalization matters">
Component names must start with a **capital letter**. `<Welcome />` is
your component; `<welcome />` would be treated as an unknown HTML tag.
This is how JSX tells components and DOM elements apart.
</Callout>

## JSX: markup inside JavaScript

The `<h1>...</h1>` syntax is **JSX**. It looks like HTML but it's
JavaScript, and it has a few rules HTML doesn't:

- **`className`, not `class`** (`class` is a reserved word in JS).
- **`{curly braces}`** embed any JavaScript expression:
  `<p>{2 + 2}</p>` renders `4`.
- **One root element** per return. Wrap siblings in a parent, or an
  empty **fragment** `<>...</>`.
- **Close every tag**, even void ones: `<img />`, `<br />`.
- **`style` takes an object** with camelCased properties:
  `style={{ fontSize: 20 }}`.

<CodeBlock
  adapter="react"
  files={[
    {
      filename: "main.tsx",
      starterCode: `import { createRoot } from "react-dom/client";

function Greeting() {
  const user = "Ada";
  const hour = 9;
  return (
    <>
      <h1 className="title">Good morning, {user}!</h1>
      <p>It is {hour < 12 ? "before" : "after"} noon.</p>
      <p style={{ color: "seagreen" }}>{2 + 2} equals four.</p>
    </>
  );
}

createRoot(document.getElementById("root")!).render(<Greeting />);
`,
    },
  ]}
/>

Notice everything inside `{}` is real JavaScript: a variable, a
ternary, an arithmetic expression. That seam between markup and code is
what makes JSX expressive.

## Components compose

The payoff is that components nest inside each other just like
elements. A `Card` can render a `Title` and an `Avatar`; a `Page`
renders many `Card`s. You build big UIs by combining small, named
pieces, each one readable on its own.

<CodeBlock
  adapter="react"
  files={[
    {
      filename: "main.tsx",
      starterCode: `import { createRoot } from "react-dom/client";

function Star() {
  return <span>⭐</span>;
}

function Rating() {
  return (
    <div>
      <Star />
      <Star />
      <Star />
    </div>
  );
}

function App() {
  return (
    <main style={{ fontFamily: "system-ui", margin: 24 }}>
      <h1>Trailblazer Boots</h1>
      <Rating />
    </main>
  );
}

createRoot(document.getElementById("root")!).render(<App />);
`,
    },
  ]}
/>

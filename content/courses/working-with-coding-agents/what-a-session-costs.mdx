A short request can start a session that reads thirty files and runs
the tests six times. Each of those steps resends the whole conversation
so far, so the input a session consumes grows much faster than the
session itself.

## Every step resends the context

- Step n sends everything from steps 1 to n-1 again. Twenty steps of

## What caching changes

{/*
- Repeated prefixes are cached, and cached input costs a tenth or less
  (How LLMs Work, "Controlling Cost"). Most of an agent's resent
  context is a repeated prefix, which is why sessions are affordable
  at all.
- Volatile content early in the context breaks the cache for everything
  after it.
*/}

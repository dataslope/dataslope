Here is the course compressed into the habits worth keeping.

## The habits

1. **Say what done looks like.** A goal, the context the agent cannot
   find, the constraints, and a check it can run.
2. **Keep tasks small.** One concern per session, sized so you will
   actually read the diff.
3. **Plan first when the task is not trivial.** Correcting a plan
   costs a sentence; correcting a diff costs a review.
4. **Start from a clean commit.** Then the whole session is one diff,
   and throwing it away is one command.
5. **Read the diff before the summary.** Files first, then tests, then
   logic.
6. **Run the tests yourself, and check they cover the change.** Break
   the change and see whether anything fails.
7. **Restart rather than argue.** After two corrections on the same
   point, a fresh session with a better request is usually faster.
8. **Limit what the agent can do.** Permissions, not the model's
   judgment, decide what a mistake can damage.

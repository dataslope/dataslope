Welcome to **Introduction to Data Visualization with Python and
Plotly Express**. This course is written for someone who has *never*
made a chart in code before — perhaps you have never written a line
of Python, perhaps you have only ever seen graphs in a newspaper or
a school textbook. You will not need a statistics background, you
will not need to install anything, and you will not need to memorize
syntax.

What you *will* do is learn to **see data**. By the end of this
course, when you look at a table of numbers you will instinctively
reach for a chart, and you will know which chart to reach for.

And you can start *right now*. **This whole course runs in your
browser** — there is nothing to install. The code block below is
live: press **Run** and a few hundred Antarctic penguins will sort
themselves into three species, each an interactive chart you can
hover and zoom.

<CodeBlock
  adapter="python"
  datasets={[{ path: "palmer-penguins.csv", stageAs: "penguins.csv" }]}
  files={[
    {
      filename: "main.py",
      initCode: `import pandas as pd
import plotly.express as px

# A small, famous dataset of 344 Antarctic penguins.
penguins = pd.read_csv("penguins.csv")`,
      starterCode: `fig = px.scatter(
    penguins,
    x="flipper_length_mm",
    y="body_mass_g",
    color="species",
    template="simple_white",
    title="Penguins: flipper length vs body mass",
)
fig.show()
`,
    },
  ]}
/>

Notice what you did *not* have to do: no loop over species, no manual
colors, no legend code. You named the columns and the *roles* they
play — `x`, `y`, `color` — and Plotly did the rest. Now **change one
thing and re-run**: replace `y="body_mass_g"` with
`y="bill_length_mm"`, or recolor by `color="island"`. Each tiny edit
asks a different question, and the picture answers instantly. That
loop — *tweak, run, look* — is the rhythm of the whole course.

## What this course is — and is not

This is a course about **visual reasoning**. We will spend more time
talking about *why* a chart works than typing chart code. We will
use [Plotly Express](https://plotly.com/python/plotly-express/) — a
small, friendly Python library that lets you go from a table to an
interactive chart in a single line — but Plotly Express is the
*vehicle*, not the destination.

This course is **not**:

- An advanced statistics or machine-learning course.
- A frontend engineering or React/D3.js course.
- A deep dive into enterprise BI platforms like Tableau or Power BI.
- A book on mathematical proofs of perception.
- A guide to deploying production dashboards on Kubernetes.

This course **is**:

- A guided tour of the *ideas* behind good visualization.
- A practical workshop on Plotly Express, one chart at a time.
- A primer on data storytelling and visualization ethics.

## What you will learn

The course is organized as a journey:

1. **The story** — How humans went from carving tally marks on bone
   to building interactive dashboards in a web browser.
2. **Visual reasoning** — Why charts work at all, and why some
   charts work better than others.
3. **Plotly Express fundamentals** — The smallest amount of Python
   you need to make your first chart.
4. **Core chart types** — Bar, line, scatter, histogram, box, pie,
   heatmap, bubble. One per page, with the *when* and *why* in
   front of the *how*.
5. **Encodings, color, and layout** — How charts gain their meaning
   from columns mapped to position, color, size, and shape.
6. **Workflows and domains** — Time series, geographic maps,
   filtering, and the rhythm of an *exploratory* analysis.
7. **Storytelling, ethics, and practice** — How to turn charts into
   arguments, how to avoid lying with graphics, and how to debug
   the visualization that "just looks wrong."

## How the interactive pages work

You already ran one chart above. Every Python code block on these
pages works the same way: it runs **in your browser** via
[Pyodide](https://pyodide.org), a full CPython 3.13 build compiled to
WebAssembly. Plotly, Pandas, and NumPy all ship with the runtime, and
larger datasets (penguins, diamonds, and a few others) are loaded for
you when a page needs them.

You will see three kinds of widgets:

1. **Executable code blocks.** Edit any snippet and click **Run**.
   Charts appear inline and are fully interactive — hover, zoom,
   pan, and toggle legend items.
2. **Multiple-choice questions.** Quick conceptual checks. Some
   pages have several, especially the foundational ones — getting
   the intuition right early on saves you hours later.
3. **Callouts** that flag tips, warnings, and "why does this
   matter?" moments.

<Callout type="info" title="Each block is isolated">
Variables defined in one `<CodeBlock>` are **not visible** to the

</Callout>

## A taste of what is coming

Here is a more ambitious visualization you will be able to write —
and *understand deeply* — by the end of the course. It is Hans
Rosling's famous animation of 50 years of global development, in one
Plotly Express call. Press the **play button** below the chart.

<CodeBlock
  adapter="python"
  files={[
    {
      filename: "main.py",
      initCode: `import plotly.express as px

# A built-in dataset of life expectancy, GDP & population over time.
df = px.data.gapminder()`,
      starterCode: `fig = px.scatter(
    df,
    x="gdpPercap",
    y="lifeExp",
    size="pop",
    color="continent",
    hover_name="country",
    animation_frame="year",
    animation_group="country",
    log_x=True,
    size_max=55,
    range_x=[100, 100000],
    range_y=[25, 90],
    template="simple_white",
    title="50 years of global development, animated",
    labels={
        "gdpPercap": "GDP per capita (USD, log scale)",
        "lifeExp": "Life expectancy (years)",
    },
)
fig.show()
`,
    },
  ]}
/>

If that looks intimidating right now — good. Every line of that
chart will feel obvious by the time you reach the end of the course.

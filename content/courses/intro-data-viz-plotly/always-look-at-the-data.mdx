title: Always Look at the Data
description: Summary statistics can describe wildly different datasets identically. The only cure is to plot the data and look.
---

There is one habit that separates careful analysts from the rest, and
it is almost embarrassingly simple: **before you trust a summary
statistic, plot the data and look at it.** This page makes the case
in the most vivid way the field has ever found, two datasets where
the numbers agree perfectly and the *pictures* could not be more
different.

## Anscombe's quartet (1973)

<Chart slug="anscombes-quartet" />

In 1973, the statistician **Francis Anscombe** built four small
datasets specifically to make a point. All four share, to two
decimal places, the same mean of x, the same mean of y, the same
variance, the same correlation, and the *same* fitted regression
line. By every standard summary number, they are identical.

Let's confirm that with the real data. Each `dataset` (I, II, III,
IV) has the same Pearson correlation.

<CodeBlock
  adapter="python"
  datasets={[{ path: "anscombes_quartet.csv", stageAs: "anscombe.csv" }]}
  files={[
    {
      filename: "main.py",
      initCode: `import pandas as pd
aq = pd.read_csv("anscombe.csv")`,
      starterCode: `summary = aq.groupby("dataset").agg(
    mean_x=("x", "mean"),
    mean_y=("y", "mean"),
    std_x=("x", "std"),
    std_y=("y", "std"),
).round(2)
summary["corr"] = aq.groupby("dataset").apply(
    lambda g: g["x"].corr(g["y"])
).round(2)

print(summary)
print("\\nFour datasets. The summary statistics are essentially identical.")
`,
    },
  ]}
/>

The means line up, the spreads line up, the correlation is about 0.82
for all four. A model would treat them as the same data. Now **plot
them**, one panel each, and the illusion collapses.

<CodeBlock
  adapter="python"
  datasets={[{ path: "anscombes_quartet.csv", stageAs: "anscombe.csv" }]}
  files={[
    {
      filename: "main.py",
      initCode: `import pandas as pd
import plotly.express as px
aq = pd.read_csv("anscombe.csv")`,
      starterCode: `fig = px.scatter(
    aq,
    x="x",
    y="y",
    facet_col="dataset",
    facet_col_wrap=2,
    template="simple_white",
    title="Anscombe's quartet, same statistics, four different shapes",
)
fig.show()
`,
    },
  ]}
/>

Look at what the numbers hid: dataset **I** is a genuine linear
cloud; **II** is a smooth curve (a straight-line model is the wrong
model entirely); **III** is a perfect line dragged off course by a
single outlier; **IV** is a vertical stack whose entire correlation
comes from one stray point. The correlation coefficient, 0.82 for
all of them, sees none of this.

## The Datasaurus Dozen (2017)

Anscombe's point was so good that, in **2017**, Justin Matejka and
George Fitzmaurice at Autodesk pushed it to its logical extreme.
Starting from Alberto Cairo's "Datasaurus", a scatter of points that
forms a cartoon **dinosaur** yet has unremarkable summary statistics,
they generated *twelve more* datasets that share the same mean,
standard deviation, and correlation to two decimal places while
looking like stars, lines, circles, and slanted clouds.

First, confirm the statistics are (almost) identical across all
thirteen:

<CodeBlock
  adapter="python"
  datasets={[{ path: "datasaurus_dozen.csv", stageAs: "datasaurus.csv" }]}
  files={[
    {
      filename: "main.py",
      initCode: `import pandas as pd
dd = pd.read_csv("datasaurus.csv")`,
      starterCode: `summary = dd.groupby("dataset").agg(
    mean_x=("x", "mean"),
    mean_y=("y", "mean"),
    std_x=("x", "std"),
    std_y=("y", "std"),
).round(1)
summary["corr"] = dd.groupby("dataset").apply(
    lambda g: g["x"].corr(g["y"])
).round(2)

print(summary)
print("\\n13 datasets. The summaries are essentially the same row, repeated.")
`,
    },
  ]}
/>

The means hover around 54 and 48, the standard deviations around 17
and 26, the correlation near −0.06, for every single one, *including*
the dinosaur. Now plot them and find the dino:

<CodeBlock
  adapter="python"
  datasets={[{ path: "datasaurus_dozen.csv", stageAs: "datasaurus.csv" }]}
  files={[
    {
      filename: "main.py",
      initCode: `import pandas as pd
import plotly.express as px
dd = pd.read_csv("datasaurus.csv")`,
      starterCode: `fig = px.scatter(
    dd,
    x="x",
    y="y",
    facet_col="dataset",
    facet_col_wrap=4,
    height=700,
    template="simple_white",
    title="The Datasaurus Dozen, identical statistics, wildly different shapes",
)
fig.update_xaxes(matches=None, showticklabels=False)
fig.update_yaxes(matches=None, showticklabels=False)
fig.show()
`,
    },
  ]}
/>

There it is, a dinosaur, a star, two parallel lines, a bullseye,
all sharing one row of summary statistics. If you had only the
numbers, you would never know.

<Callout type="warn" title="The cheapest insight in this whole course">
Mean, standard deviation, and correlation are a three-number summary
of a cloud that may contain a dinosaur. The shapes they miss,
curves, clusters, outliers, two populations mixed together, are
*exactly* the ones that change the conclusion. Before you summarize,
before you model, before you trust a single statistic: **scatter the
data and look at it.** It costs one line of code.
</Callout>

You've gone from an empty file to interactive, styled, multi-file
pages, and had a first taste of the two tools (Tailwind, React)
you'll meet on nearly every modern team. Here's how to keep the
momentum.

## Keep building, the playgrounds

Everything in this course also exists as a full-page playground with
multi-file tabs, examples, and export:

- **[HTML/CSS/JS playground](/playground/web)**, the same live
  preview, with room to build multi-page experiments (every `.html`
  tab becomes a runnable entry in the Run menu).
- **[React playground](/playground/react)**, TSX with npm imports:
  try `import confetti from "canvas-confetti"` and call
  `confetti()` on a button click.

Project ideas sized for a weekend:

1. **A personal homepage**, bio, links, a photo, your own color
   scheme. Pure HTML/CSS.
2. **A quiz card**, question, three answer buttons, score tracking.
   HTML/CSS/JS.
3. **A packing-list app**, add items with a form, tick them off,
   count what's left. Do it in vanilla JS first, then rebuild it in
   React and compare.

## Reference material worth bookmarking

- **MDN Web Docs**, the canonical reference for every element,
  property, and API in this course.
- **web.dev**, Google's guides on layout, performance, and
  accessibility.
- **The Tailwind and React docs**, both are unusually good, with
  live examples in the same spirit as this course.

## The habits that matter

If you remember three things from this course:

1. **Structure, style, behaviour**, keep HTML, CSS, and JavaScript
   doing their own jobs, whatever framework you use.
2. **The box model explains most layout mysteries**, when in doubt,
   inspect the padding/border/margin.
3. **State drives the display**, whether it's a variable and
   `textContent` or `useState` and JSX, the display should be a
   function of the data.

Happy building!

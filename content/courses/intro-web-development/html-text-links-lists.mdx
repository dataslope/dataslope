Structure isn't only headings. This lesson covers the elements you'll
type most often: inline text markup, the anchor element that puts the
"hyper" in hypertext, and lists.

## Attributes

Elements can carry **attributes**, name/value pairs inside the
opening tag that configure the element:

```html
<a href="https://developer.mozilla.org">MDN Web Docs</a>
```

`href` is an attribute of the `<a>` (anchor) element: the destination
this link points to. Attribute values always belong in quotes.

## Inline text elements

Block elements like `<p>` stack vertically; **inline** elements mark
up meaning *within* a line of text:

- `<strong>`, importance (rendered bold by default)
- `<em>`, emphasis (rendered italic)
- `<code>`, a fragment of code
- `<a href="…">`, a link

## Lists

Two kinds you'll use constantly:

- `<ul>`, an *unordered* list (bullets)
- `<ol>`, an *ordered* list (numbers)

Both contain only `<li>` (list item) children.

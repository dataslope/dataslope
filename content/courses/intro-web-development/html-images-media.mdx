## The image element

`<img>` is a **void element**, it has no closing tag and no content
of its own. Two attributes matter most:

- **`src`**, where the image lives (a URL or a file path).
- **`alt`**, a text description read aloud by screen readers and shown
  if the image fails to load.

<Figure
  slug="web-html-images-media-inline-cutout"
  alt="A page panel with a picture plate mounted in it and a small play tab on a second plate below"
/>

```html
<img src="https://picsum.photos/240/160" alt="A random placeholder photo" />
```

<Callout type="warn" title="alt is not optional">
Every content image needs an `alt`. Write what the image *shows*, not
"image of…". For a purely decorative image, use an empty `alt=""` so
screen readers skip it, that's a deliberate signal, not a missing
attribute.
</Callout>

Try editing the `alt` text and the dimensions below, then Run:

<CodeBlock
  adapter="web"
  files={[
    {
      filename: "index.html",
      starterCode: `<!DOCTYPE html>
<html>
  <head>
    <style>
    body {
      font-family: system-ui, sans-serif;
      margin: 2rem;
    }
    img {
      border-radius: 12px;
    }
    </style>
  </head>
  <body>
    <h1>A photo</h1>
    <img
      src="https://picsum.photos/id/1025/320/200"
      alt="A pug wrapped in a blanket"
      width="320"
      height="200"
    />
  </body>
</html>
`,
    },
  ]}
/>

Setting `width` and `height` (or the CSS equivalents) lets the browser
reserve space before the image loads, so the page doesn't jump around
as pictures arrive.

Which format you pick is usually the single biggest lever on page weight,
and the gaps between them are larger than most people assume.

## Figures and captions

When an image needs a caption, wrap it in `<figure>` and add a
`<figcaption>`. This ties the caption to the image *semantically*, not
just visually:

```html
<figure>
  <img src="chart.png" alt="Revenue rising each quarter" />
  <figcaption>Quarterly revenue, 2024</figcaption>
</figure>
```

## Audio and video

`<audio>` and `<video>` embed media with built-in controls. Add the
`controls` attribute so the browser draws a play button, scrubber, and
volume slider:

<CodeBlock
  adapter="web"
  files={[
    {
      filename: "index.html",
      starterCode: `<!DOCTYPE html>
<html>
  <head>
    <style>
    body {
      font-family: system-ui, sans-serif;
      margin: 2rem;
    }
    video {
      max-width: 100%;
      border-radius: 12px;
    }
    </style>
  </head>
  <body>
    <h1>An embedded video</h1>
    <video
      src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
      controls
      width="480"
    >
    </video>
    <p>The <code>controls</code> attribute draws the play/pause UI.</p>
  </body>
</html>
`,
    },
  ]}
/>

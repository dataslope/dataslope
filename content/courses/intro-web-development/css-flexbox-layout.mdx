---
title: CSS — Flexbox Layout
description: Arranging boxes in rows and columns with display flex, gap, justify-content, and align-items.
---

By default, block elements stack top-to-bottom. **Flexbox** is the
modern way to arrange them any other way: navigation bars, card rows,
centered heroes, sidebar layouts.

One rule changes everything:

```css
.container {
  display: flex;
}
```

The container's direct children become **flex items** and line up in
a row. From there, a handful of container properties do most layout
work on the web:

| Property | What it controls |
| --- | --- |
| `flex-direction` | `row` (default) or `column` |
| `gap` | space *between* items (no margin juggling) |
| `justify-content` | distribution along the main axis — `flex-start`, `center`, `space-between`… |
| `align-items` | alignment on the cross axis — `stretch`, `center`… |
| `flex-wrap` | allow items to wrap onto new lines |

  font-family: system-ui, sans-serif;
  margin: 0;
}

.navbar {
  display: flex;
  align-items: center;
  gap: 1rem;
  padding: 0.75rem 1.25rem;
  background: #0f172a;
}

.brand {
  color: white;
  font-weight: 700;
  /* pushes everything after it to the right: */
  margin-right: auto;
}

.navbar a {
  color: #cbd5e1;
  text-decoration: none;
}

.cards {
  display: flex;
  gap: 1rem;
  padding: 1.25rem;
}

.card {
  flex: 1;
  padding: 2rem 1rem;
  text-align: center;
  font-weight: 600;
  border-radius: 10px;
  background: #dbeafe;
}
`,
    },
  ]}
/>

Two patterns worth memorizing from that stylesheet:

- **`margin-right: auto`** on one flex item absorbs all free space,
  shoving its siblings to the far end — the classic navbar split.
- **`flex: 1`** on the cards makes each one stretch to share the row
  equally.

And the most-searched CSS question of all time — *center something
horizontally and vertically* — is three lines now:

```css
.parent { display: flex; justify-content: center; align-items: center; }
```

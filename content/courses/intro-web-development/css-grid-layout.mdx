Flexbox arranges items along **one** axis, a row or a column. **CSS
Grid** arranges them in **two** at once: rows *and* columns. It's the
tool for page layouts, image galleries, and any "grid of cards".

One declaration turns an element into a grid, and one more defines its
columns:

```css
.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* three equal columns */
  gap: 1rem;
}
```

## The `fr` unit

`fr` means "one fraction of the free space". `1fr 1fr 1fr` splits the
row into three equal columns. `2fr 1fr` makes the first column twice
as wide as the second. It's like `flex: 1`, but for the whole grid at
once.

The `repeat()` helper saves typing: `repeat(3, 1fr)` is exactly
`1fr 1fr 1fr`.

Change `repeat(3, 1fr)` to `repeat(2, 1fr)` and Run: the same six
cells reflow into two columns of three. That's the power of grid, the
markup never changes, only the template.

## Auto-fit: responsive with zero media queries

This one line builds a gallery that fits as many columns as the width
allows, wrapping automatically:

```css
grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
```

"As many `1fr` columns as fit, each at least `150px` wide." Resize the
preview and watch the column count change on its own.

## Grid vs. Flexbox

- **Flexbox**: content laid out in *one* direction, navbars, button
  rows, a label next to a value.
- **Grid**: layout defined in *two* directions, page scaffolding,
  card galleries, anything that lines up in rows *and* columns.

They compose happily: a grid of cards where each card is a flex
column is completely normal.

CSS (*Cascading Style Sheets*) describes what your HTML **looks
like**. A stylesheet is a list of **rules**, and every rule has the
same shape:

<Figure
  slug="web-css-getting-started-cutout"
  alt="CSS: getting started, an isometric illustration"
/>

```css
selector {
  property: value;
  property: value;
}
```

- The **selector** picks which elements the rule applies to.
- Each **declaration** (`property: value;`) sets one visual aspect.

## The three selectors you'll use most

```css
p          { color: #334155; }   /* every <p> element        */
.note      { background: #fef9c3; } /* every element with class="note" */
#site-title { letter-spacing: 2px; } /* the ONE element with id="site-title" */
```

- **Element selectors** (`p`, `h1`, `li`) style every element of that
  type.
- **Class selectors** (`.note`) match the `class` attribute. Classes
  are reusable, many elements can share one class, and one element
  can carry several classes.
- **ID selectors** (`#site-title`) match a unique `id`. IDs must be
  unique per page; prefer classes for styling and save IDs for
  linking and JavaScript.

## A stylesheet in its own file

Real projects keep CSS out of the HTML. The `<link>` element in the
head pulls in `styles.css`, switch between the two tabs below:

<CodeBlock
  adapter="web"
  entryFilename="index.html"
  files={[
    {
      filename: "index.html",
      starterCode: `<!DOCTYPE html>
<html>
  <head>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <h1 id="site-title">The Daily Pixel</h1>
    <p>A newsletter about tiny graphics and big ideas.</p>
    <p class="note">New issues every Friday.</p>
    <p>No spam, unsubscribe anytime.</p>
  </body>
</html>
`,
    },
    {
      filename: "styles.css",
      starterCode: `body {
  font-family: Georgia, serif;
  margin: 2.5rem;
  color: #334155;
}

#site-title {
  color: #0f172a;
  letter-spacing: 1px;
  border-bottom: 3px solid #f59e0b;
  padding-bottom: 0.3rem;
}

.note {
  background: #fef9c3;
  padding: 0.5rem 0.75rem;
  border-radius: 6px;
}
`,
    },
  ]}
/>

Experiments to try: change `Georgia, serif` to `system-ui,
sans-serif`; give `.note` a `border`; add a `p { line-height: 1.7 }`
rule and notice every paragraph react.

## Colors

You'll meet three common notations, all equivalent in power:
named colors (`tomato`), hex (`#f59e0b`), and `rgb(245, 158, 11)`.
Pick per taste; tools convert freely between them.

When the browser reads your HTML, it builds a live, in-memory model of
the page called the **DOM** (*Document Object Model*), a tree of
objects, one per element. JavaScript can reach into that tree and
change anything: text, attributes, styles, structure. Every "the page
just updated" moment on the web is DOM manipulation.

## Selecting elements

The entry point is the global `document` object:

```js
var heading = document.querySelector("h1");        // first match
var note    = document.querySelector(".note");     // by class
var button  = document.querySelector("#save");     // by id
var items   = document.querySelectorAll("li");     // ALL matches
```

`querySelector()` takes exactly the selectors you learned in CSS, one
language, two uses.

## Changing what you selected

```js
heading.textContent = "New title";        // replace the text
note.classList.add("visible");           // add / remove / toggle classes
button.style.background = "tomato";      // set one inline style
```

Prefer `classList` over `style` for anything you already have CSS
for, it keeps the "what it looks like" decision in the stylesheet.

      <li>Water the plants</li>
      <li>Answer three emails</li>
      <li>Stretch</li>
    </ul>

    <script src="script.js"></script>
  </body>
</html>
`,
    },
    {
      filename: "script.js",
      starterCode: `// Select elements with the same selectors CSS uses.
var title = document.querySelector("#title");
var items = document.querySelectorAll("li");

console.log("The list has", items.length, "chores");

// Change text from code:
title.textContent = "Chore list (" + items.length + " items)";

// Mark the first chore as done by ADDING A CLASS,
// the .done styling itself lives in the stylesheet.
items[0].classList.add("done");

console.log("First chore:", items[0].textContent);
`,
    },
  ]}
/>

Note where the `<script src="script.js">` tag sits: at the **end of
`<body>`**. Scripts run the moment the parser reaches them, placing
them last guarantees every element above already exists, so
`querySelector()` finds what it's looking for.

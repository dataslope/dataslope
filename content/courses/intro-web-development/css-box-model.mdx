Every element the browser renders is a rectangle, and every rectangle
has the same four layers, from the inside out:

<Figure
  slug="web-css-box-model-cutout"
  alt="CSS: the box model, an isometric illustration"
/>

1. **Content**, the text or image itself; sized by `width`/`height`.
2. **Padding**, space between the content and the border. Shares the
   element's background.
3. **Border**, the (optionally visible) edge of the box.
4. **Margin**, space *outside* the border, pushing neighbours away.
   Always transparent.

<Figure
  slug="web-css-box-model-inline-cutout"
  alt="One block shown in cross-section as four nested frames of different colours, from the content core outward to the outermost margin"
/>

If CSS ever feels mysterious, "why is there a gap here?", "why is
this box wider than I said?", the answer is almost always the box
model.

Try setting `padding: 0`, then `margin: 0`, and watch which gap
disappears. That's the fastest way to internalize the difference.

## `box-sizing`, one rule to keep

By default, `width` sets only the *content* width, so padding and
border make the box bigger than the number you wrote. Nearly every
real stylesheet opts out of that surprise:

```css
* { box-sizing: border-box; }   /* width now includes padding + border */
```

## Shorthands

`padding: 16px` sets all four sides. Two values (`padding: 8px 16px`)
set vertical then horizontal; four values go clockwise from the top.
`margin` works the same way. `border: 4px solid #2563eb` combines
width, style, and color.

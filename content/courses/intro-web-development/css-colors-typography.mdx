Before layout, most of "looking good" is **color and type**. A page
with sensible fonts, spacing, and a restrained palette reads as
professional even with the simplest layout.

## Colors, four ways to say the same thing

CSS accepts color in several notations. These are all the same blue:

| Notation | Example |
| --- | --- |
| Named | `royalblue` |
| Hex | `#4169e1` |
| RGB | `rgb(65, 105, 225)` |
| HSL | `hsl(225, 73%, 57%)` |

`rgb()` and `hsl()` can take a fourth value for **alpha**
(transparency): `rgb(65 105 225 / 0.5)` is half-transparent.
`hsl()` is the friendliest for tweaking by hand, nudge the first
number to change the hue, the last to change lightness.

## Typography properties worth knowing

| Property | Controls |
| --- | --- |
| `font-family` | The typeface, with fallbacks |
| `font-size` | Text size |
| `font-weight` | `400` normal, `700` bold |
| `line-height` | Vertical space between lines |
| `letter-spacing` | Space between characters |
| `text-align` | `left`, `center`, `right`, `justify` |

The single highest-impact typography rule is a comfortable
**`line-height`** (around `1.5` for body text) and a **readable
measure** (line length), controlled by capping the container width.

## Web fonts

The `font-family` list is a set of fallbacks: the browser uses the
first one that's available. `system-ui` means "the operating system's
own UI font", which loads instantly and looks native everywhere. For
custom fonts you'd link a font file (e.g. from Google Fonts); the
fallback list is what shows while it loads.

You opened the box. Here is what was inside, compressed.

## The mechanisms

1. **Tokens.** Text becomes chunks, learned by frequency through
   byte-pair encoding. Common text is one token, rare text shatters.
2. **Embeddings.** Each token becomes a vector, and meaning becomes
   geometry. Position must be added separately.
3. **Attention.** Every token compares against every other, and each
   builds an updated representation from a weighted blend. Cost is
   quadratic in length.
4. **Layers.** Attention and feed-forward, stacked dozens deep, with
   most parameters in the feed-forward halves.
5. **Softmax and sampling.** Scores become a distribution, and a
   configurable draw picks one token. Then the whole thing repeats.

## What they explain

| Behavior | Mechanism |
| --- | --- |
| Cannot count letters in a word | It receives tokens, not characters |
| Non-English text costs more | The tokenizer was fitted mostly to English |
| Output costs 5 to 6x input | Input is parallel, output is sequential |
| Cached input costs a tenth | Stored state is retrieved, not recomputed |
| Same prompt, different answers | Sampling draws from a distribution |
| Confident hallucinations | Plausible continuation is the only objective |
| Facts in mid-context get missed | Recall is U-shaped across position |
| Long conversations cost more than they look | Every turn resends the whole history |
| Reasoning helps math and not recall | Extra compute restructures, it does not retrieve |
| Leaderboard rank misses your task | Benchmarks measure benchmarks |

## Three things to actually do

**Estimate before you build.** Take the cost calculator from
*Estimating Cost*, put your real workload into it, and look at which
line dominates. It is rarely the one you expect.

**Build the harness.** Thirty examples of your own task with known
answers. It takes an afternoon and it outlives every model you will
evaluate with it.

**Put stable content first.** Volatile content (timestamps, ids, the
user's question) goes at the end of the prompt. This one habit is
worth a large fraction of your caching discount.

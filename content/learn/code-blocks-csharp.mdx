C# is compiled by **Roslyn** running on the **.NET WebAssembly
runtime**. Top-level statements are supported, so you can write
scripts without a wrapping class.

## Hello, world

<CodeBlock
  adapter="csharp"
  files={[
    {
      filename: "main.cs",
      starterCode: `using System;

Console.WriteLine("Hello, C#!");
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"  i = {i}");
}
`,
    },
  ]}
/>

## LINQ over collections

<CodeBlock
  adapter="csharp"
  files={[
    {
      filename: "main.cs",
      starterCode: `using System;
using System.Linq;

var xs = new[] { 3, 1, 4, 1, 5, 9, 2, 6, 5, 3 };
var sorted = xs.OrderBy(x => x).ToArray();
Console.WriteLine($"sorted: [{string.Join(", ", sorted)}]");
Console.WriteLine($"sum:    {xs.Sum()}");
Console.WriteLine($"mean:   {xs.Average():F2}");
`,
    },
  ]}
/>

## Multiple files

A top-level `Program.cs` can reference types defined in sibling files. Every workspace file is fed to the compiler so additional `.cs` files participate in the build.

<CodeBlock
  adapter="csharp"
  entryFilename="Program.cs"
  files={[
    {
      filename: "Program.cs",
      starterCode: `var g = new Greeter("C# Playground");
Console.WriteLine(g.Hello());
Console.WriteLine(g.Bye());
`,
    },
    {
      filename: "Greeter.cs",
      starterCode: `public class Greeter
{
    private readonly string _name;

    public Greeter(string name)
    {
        _name = name;
    }

    public string Hello() => $"Hello, {_name}!";
    public string Bye() => $"Goodbye, {_name}!";
}
`,
    },
  ]}
/>

## Initialization code

`initCode` is read-only setup prepended to your snippet on every Run — handy
for `using` directives without cluttering the part you edit. Init of 3 lines
or fewer shows a compact read-only header; 4 lines or more collapses behind a
"Click to expand" toggle.

A short init (3 lines or fewer):

<CodeBlock
  adapter="csharp"
  files={[
    {
      filename: "main.cs",
      initCode: `using System;
using System.Linq;`,
      starterCode: `// The using directives come from the initialization code above.
int[] xs = { 1, 2, 3 };
Console.WriteLine($"sum = {xs.Sum()}");
`,
    },
  ]}
/>

A longer init (4 lines or more), collapsed by default:

<CodeBlock
  adapter="csharp"
  files={[
    {
      filename: "main.cs",
      initCode: `using System;
using System.Linq;
using System.Collections.Generic;
using System.Text;`,
      starterCode: `// The using directives come from the initialization code above.
var names = new List<string> { "Ada", "Linus", "Grace" };
var sb = new StringBuilder();
foreach (var n in names.OrderBy(x => x))
    sb.Append(n).Append(" ");
Console.WriteLine(sb.ToString().Trim());
`,
    },
  ]}
/>

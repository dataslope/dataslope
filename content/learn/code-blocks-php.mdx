PHP runs through **php-wasm** — a WebAssembly build of the PHP
interpreter. Each block executes in a fresh process, so superglobals
and class definitions don't carry over.

## Hello, world

<CodeBlock
  adapter="php"
  files={[
    {
      filename: "main.php",
      starterCode: `<?php

echo 'Hello from PHP ' . PHP_VERSION . "!\\n";

$names = ['Ada', 'Linus', 'Grace'];
foreach ($names as $i => $name) {
    echo ($i + 1) . ". $name\\n";
}
`,
    },
  ]}
/>

## Arrays and JSON

<CodeBlock
  adapter="php"
  files={[
    {
      filename: "main.php",
      starterCode: `<?php

$people = [
    ['name' => 'Ada', 'score' => 92],
    ['name' => 'Linus', 'score' => 88],
    ['name' => 'Grace', 'score' => 95],
];
usort($people, fn($a, $b) => $b['score'] - $a['score']);
echo json_encode($people, JSON_PRETTY_PRINT);
`,
    },
  ]}
/>

## Multiple files

`require_once` a sibling file just like a regular PHP project. Every workspace file lives in the same directory inside the runtime so `__DIR__` resolves correctly.

<CodeBlock
  adapter="php"
  entryFilename="index.php"
  files={[
    {
      filename: "index.php",
      starterCode: `<?php

require_once __DIR__ . '/greetings.php';

echo hello('PHP Playground') . "\\n";
echo bye('PHP Playground') . "\\n";
`,
    },
    {
      filename: "greetings.php",
      starterCode: `<?php

function hello(string $name): string
{
    return "Hello, {$name}!";
}

function bye(string $name): string
{
    return "Goodbye, {$name}!";
}
`,
    },
  ]}
/>

## Initialization code

`initCode` is read-only setup prepended to your snippet on every Run — handy
for imports or sample data without cluttering the part you edit. Init of 3
lines or fewer shows a compact read-only header; 4 lines or more collapses
behind a "Click to expand" toggle.

A short init (3 lines or fewer):

<CodeBlock
  adapter="php"
  files={[
    {
      filename: "main.php",
      initCode: `<?php
$names = ["Ada", "Linus", "Grace"];`,
      starterCode: `// $names comes from the initialization code above.
foreach ($names as $i => $name) {
    echo ($i + 1) . ". " . $name . PHP_EOL;
}
`,
    },
  ]}
/>

A longer init (4 lines or more), collapsed by default:

<CodeBlock
  adapter="php"
  files={[
    {
      filename: "main.php",
      initCode: `<?php
$people = [
    ["name" => "Ada", "score" => 92],
    ["name" => "Linus", "score" => 88],
];`,
      starterCode: `// $people comes from the initialization code above.
usort($people, fn($a, $b) => $b["score"] - $a["score"]);
echo json_encode($people, JSON_PRETTY_PRINT) . PHP_EOL;
`,
    },
  ]}
/>

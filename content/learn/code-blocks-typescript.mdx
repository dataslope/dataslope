TypeScript is type-checked-and-transpiled to JavaScript using the
TypeScript compiler shipped with the page, then executed the same way
the [JavaScript](/learn/javascript) blocks are.

## Types and interfaces

<CodeBlock
  adapter="typescript"
  starterCode={`interface Point { x: number; y: number }
const p: Point = { x: 3, y: 4 };
const dist = Math.hypot(p.x, p.y);
console.log(\`distance = \${dist}\`);
`}
/>

## Generics

<CodeBlock
  adapter="typescript"
  starterCode={`function pluck<T, K extends keyof T>(items: T[], key: K): T[K][] {
  return items.map((it) => it[key]);
}

const users = [
  { id: 1, name: "Ada" },
  { id: 2, name: "Linus" },
  { id: 3, name: "Grace" },
];
console.log(pluck(users, "name"));
`}
/>

## Multiple files

Import a typed helper module from a sibling file. The TypeScript runtime transpiles every workspace file before execution, so types from imported modules are checked just like a regular project.

<CodeBlock
  adapter="typescript"
  entryFilename="index.ts"
  files={[
    {
      filename: "index.ts",
      initialContent: `import { hello, bye } from "./greetings";

console.log(hello("TypeScript Playground"));
console.log(bye("TypeScript Playground"));
`,
    },
    {
      filename: "greetings.ts",
      initialContent: `export function hello(name: string): string {
  return \`Hello, \${name}!\`;
}

export function bye(name: string): string {
  return \`Goodbye, \${name}!\`;
}
`,
    },
  ]}
/>

## Initialization code

`initCode` is read-only setup prepended to your snippet on every Run — handy
for imports or sample data without cluttering the part you edit. Init of 3
lines or fewer shows a compact read-only header; 4 lines or more collapses
behind a "Click to expand" toggle.

A short init (3 lines or fewer):

<CodeBlock
  adapter="typescript"
  initCode={`type Celsius = number;`}
  starterCode={`// 'Celsius' comes from the initialization code above.
const t: Celsius = 25;
console.log(t + " degrees C");
`}
/>

A longer init (4 lines or more), collapsed by default:

<CodeBlock
  adapter="typescript"
  initCode={`interface Point {
  x: number;
  y: number;
}`}
  starterCode={`// 'Point' comes from the initialization code above.
const p: Point = { x: 3, y: 4 };
console.log("distance =", Math.hypot(p.x, p.y));
`}
/>

## 1. Typed function signatures

<ChallengeCard
  adapter="typescript"
  title="Generic identity function"
  instructions={`Define a generic function \`identity<T>(x: T): T\` that returns its argument unchanged. The test checks that it preserves both the value and the type at runtime (TypeScript erases types, so we only verify the value).`}
  files={[
    {
      filename: "main.ts",
      starterCode: `function identity<T>(x: T): T {
  // your code here
  return x;
}

console.log(identity(42));
console.log(identity("hello"));
`,
      solutionCode: `function identity<T>(value: T): T {
  return value;
}

console.log(identity<number>(42));
console.log(identity<string>("hello"));
`,
    },
  ]}
  tests={[
    {
      id: "number",
      name: "Preserves a number",
      description: "identity(42) === 42",
      code: `if (identity(42) !== 42) throw new Error("expected 42");`,
    },
    {
      id: "string",
      name: "Preserves a string",
      description: "identity('hi') === 'hi'",
      code: `if (identity("hi") !== "hi") throw new Error("expected 'hi'");`,
    },
    {
      id: "object",
      name: "Preserves object reference",
      description: "identity(obj) === obj",
      code: `const obj = { a: 1 }; if (identity(obj) !== obj) throw new Error("expected same reference");`,
    },
  ]}
/>

## 2. Discriminated unions

<ChallengeCard
  adapter="typescript"
  title="Area of a Shape"
  instructions={`Define a function \`area(shape: Shape)\` that returns the area of the given shape, where \`Shape\` is the discriminated union below.

- Circle: π · r²
- Square: side²
- Rect: width · height`}
  files={[
    {
      filename: "main.ts",
      initCode: `type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "square"; side: number }
  | { kind: "rect"; width: number; height: number };
`,
      starterCode: `function area(shape: Shape): number {
  // your code here
  return 0;
}

console.log(area({ kind: "circle", radius: 1 }));
console.log(area({ kind: "square", side: 4 }));
console.log(area({ kind: "rect", width: 3, height: 5 }));
`,
      solutionCode: `function area(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius * shape.radius;
    case "square":
      return shape.side * shape.side;
    case "rect":
      return shape.width * shape.height;
  }
}

console.log(area({ kind: "circle", radius: 1 }));
console.log(area({ kind: "square", side: 4 }));
console.log(area({ kind: "rect", width: 3, height: 5 }));
`,
    },
  ]}
  tests={[
    {
      id: "circle",
      name: "Circle uses π·r²",
      description: "radius=2 → ≈12.566",
      code: `const a = area({ kind: "circle", radius: 2 }); if (Math.abs(a - Math.PI*4) > 1e-6) throw new Error(\`Got \${a}\`);`,
    },
    {
      id: "square",
      name: "Square uses side²",
      description: "side=4 → 16",
      code: `if (area({ kind: "square", side: 4 }) !== 16) throw new Error("expected 16");`,
    },
    {
      id: "rect",
      name: "Rect uses w·h",
      description: "3 × 5 = 15",
      code: `if (area({ kind: "rect", width: 3, height: 5 }) !== 15) throw new Error("expected 15");`,
    },
  ]}
/>

## Multi-file challenge

Multi-file challenges open with a non-sortable, non-closeable tab bar
above the editor. Every file is staged into almostnode's virtual
filesystem before each run, so the entry module can `import` from
sibling files.

<ChallengeCard
  adapter="typescript"
  title="Implement greet() in utils.ts"
  instructions={`Open \`utils.ts\` and implement \`greet(name)\` so that it returns the string \`"Hello, <name>!"\`. The entry script \`main.ts\` already imports your function and prints the result.`}
  entryFilename="main.ts"
  files={[
    {
      filename: "main.ts",
      starterCode: `import { greet } from "./utils";\nconsole.log(greet("World"));\n`,
    },
    {
      filename: "utils.ts",
      starterCode: `export function greet(name: string): string {\n  // your code here\n  return "";\n}\n`,
      solutionCode: `export function greet(name: string): string {\n  return \`Hello, \${name}!\`;\n}\n`,
    },
  ]}
  tests={[
    {
      id: "greets",
      name: "Prints `Hello, World!`",
      description: "main runs and greet returns the expected value",
      expect: { stdoutEquals: "Hello, World!" },
    },
  ]}
/>

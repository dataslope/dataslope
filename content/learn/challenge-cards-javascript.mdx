JavaScript challenges run via the **almostnode** WASM runtime — no
server, no Node install. Each card here uses the same JS harness; only
the test bodies differ.

## 1. Function return value

<ChallengeCard
  adapter="javascript"
  title="Sum of an array"
  instructions={`Define a function \`sumArray(xs)\` that returns the sum of all numbers in the array \`xs\`. An empty array should return \`0\`.`}
  starterCode={`function sumArray(xs) {
  // your code here
  return 0;
}

console.log(sumArray([1, 2, 3, 4, 5]));
`}
  solutionCode={`function sumArray(xs) {
  return xs.reduce((a, b) => a + b, 0);
}

console.log(sumArray([1, 2, 3, 4, 5]));
`}
  tests={[
    {
      id: "small",
      name: "Small array",
      description: "[1, 2, 3, 4, 5] → 15",
      code: `if (sumArray([1, 2, 3, 4, 5]) !== 15) throw new Error("sumArray([1..5]) should be 15");`,
    },
    {
      id: "empty",
      name: "Empty array returns 0",
      description: "[] → 0",
      code: `if (sumArray([]) !== 0) throw new Error("sumArray([]) should be 0");`,
    },
    {
      id: "negatives",
      name: "Handles negative numbers",
      description: "[-1, -2, 3] → 0",
      code: `if (sumArray([-1, -2, 3]) !== 0) throw new Error("sumArray([-1,-2,3]) should be 0");`,
    },
  ]}
/>

## 2. Object transformations

<ChallengeCard
  adapter="javascript"
  title="Group orders by customer"
  instructions={`Given the array \`orders\` defined above, build an object called \`byCustomer\` mapping each customer name to the total amount they spent (summed across their orders).`}
  initCode={`const orders = [
  { customer: "Ada",   amount: 120 },
  { customer: "Linus", amount: 80 },
  { customer: "Ada",   amount: 30 },
  { customer: "Grace", amount: 200 },
  { customer: "Linus", amount: 50 },
];
`}
  starterCode={`let byCustomer = null; // TODO

console.log(byCustomer);
`}
  solutionCode={`let byCustomer = {};
for (const o of orders) {
  byCustomer[o.customer] = (byCustomer[o.customer] || 0) + o.amount;
}

console.log(byCustomer);
`}
  tests={[
    {
      id: "is_object",
      name: "byCustomer is an object",
      description: "Should be a plain object, not null",
      code: `if (byCustomer === null || typeof byCustomer !== "object") throw new Error("byCustomer should be an object");`,
    },
    {
      id: "ada",
      name: "Ada's total = 150",
      description: "Two orders: 120 + 30",
      code: `if (byCustomer.Ada !== 150) throw new Error(\`Ada should be 150, got \${byCustomer.Ada}\`);`,
    },
    {
      id: "linus",
      name: "Linus' total = 130",
      description: "Two orders: 80 + 50",
      code: `if (byCustomer.Linus !== 130) throw new Error(\`Linus should be 130, got \${byCustomer.Linus}\`);`,
    },
    {
      id: "grace",
      name: "Grace's total = 200",
      description: "Single order: 200",
      code: `if (byCustomer.Grace !== 200) throw new Error(\`Grace should be 200, got \${byCustomer.Grace}\`);`,
    },
  ]}
/>

## 3. Async / promise basics

<ChallengeCard
  adapter="javascript"
  title="Wrap a callback in a Promise"
  instructions={`Define a function \`delay(ms)\` that returns a Promise which resolves to the string \`"done"\` after \`ms\` milliseconds. Use \`setTimeout\`.`}
  starterCode={`function delay(ms) {
  // your code here
}

delay(10).then((v) => console.log(v));
`}
  solutionCode={`function delay(ms) {
  return new Promise((resolve) => setTimeout(() => resolve("done"), ms));
}

delay(10).then((v) => console.log(v));
`}
  tests={[
    {
      id: "returns_promise",
      name: "delay returns a Promise",
      description: "delay(0) should be thenable",
      code: `const p = delay(0); if (!p || typeof p.then !== "function") throw new Error("delay should return a Promise");`,
    },
    {
      id: "resolves_to_done",
      name: "Resolves to `done`",
      description: "delay(5) eventually resolves to 'done'",
      code: `const v = await delay(5); if (v !== "done") throw new Error(\`Expected "done", got \${v}\`);`,
    },
  ]}
/>

## Multi-file challenge

Multi-file challenges open with a non-sortable, non-closeable tab bar
above the editor. Click a filename to switch buffers. Every file is
staged into almostnode's virtual filesystem before each run, so the
entry module can `require()` sibling files.

<ChallengeCard
  adapter="javascript"
  title="Implement greet() in utils.js"
  instructions={`Open \`utils.js\` and implement \`greet(name)\` so that it returns the string \`"Hello, <name>!"\`. The entry script \`main.js\` already requires your function and prints the result.`}
  entryFilename="main.js"
  files={[
    {
      filename: "main.js",
      initialContent: `const { greet } = require("./utils");\nconsole.log(greet("World"));\n`,
    },
    {
      filename: "utils.js",
      initialContent: `function greet(name) {\n  // your code here\n  return "";\n}\n\nmodule.exports = { greet };\n`,
      solutionContent: `function greet(name) {\n  return \`Hello, \${name}!\`;\n}\n\nmodule.exports = { greet };\n`,
    },
  ]}
  tests={[
    {
      id: "greets",
      name: "Prints `Hello, World!`",
      description: "main runs and greet returns the expected value",
      expect: { stdoutEquals: "Hello, World!" },
    },
  ]}
/>

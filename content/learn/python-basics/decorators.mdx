A **decorator** is just a function that takes another function and
returns a new one. The `@decorator` syntax is sugar for that pattern.

## The minimal decorator

<CodeBlock
  adapter="python"
  initialCode={`def shout(fn):
    def wrapper(*args, **kwargs):
        return fn(*args, **kwargs).upper()
    return wrapper

@shout
def greet(name):
    return f"hello, {name}"

print(greet("Ada"))
`}
/>

`@shout` is equivalent to writing:

```python
def greet(name):
    return f"hello, {name}"

greet = shout(greet)
```

The decorator wraps `greet` so that every call goes through `wrapper`,
which uppercases the result.

## Preserve metadata with `functools.wraps`

Without `wraps`, the wrapped function loses its name, docstring, and
signature. **Always** use `functools.wraps` in real decorators.

<CodeBlock
  adapter="python"
  initialCode={`from functools import wraps

def shout(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        return fn(*args, **kwargs).upper()
    return wrapper

@shout
def greet(name):
    "Return a greeting."
    return f"hello, {name}"

print(greet.__name__)
print(greet.__doc__)
`}
/>

## A useful example: timing

<CodeBlock
  adapter="python"
  initialCode={`import time
from functools import wraps

def timed(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = fn(*args, **kwargs)
        elapsed_ms = (time.perf_counter() - start) * 1000
        print(f"{fn.__name__} took {elapsed_ms:.2f} ms")
        return result
    return wrapper

@timed
def slow_square(n):
    total = 0
    for i in range(n):
        total += i * i
    return total

print(slow_square(100_000))
`}
/>

## Decorators with arguments

If your decorator itself takes parameters, you need three levels of
nesting: outer call returns the real decorator, which returns the
wrapper.

<CodeBlock
  adapter="python"
  initialCode={`from functools import wraps

def repeat(times):
    def decorator(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = fn(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def hi():
    print("hi")

hi()
`}
/>

## Stacking decorators

You can apply more than one. They are applied bottom-up: the closest
to the function runs first.

<CodeBlock
  adapter="python"
  initialCode={`from functools import wraps

def bracketed(fn):
    @wraps(fn)
    def wrapper(*a, **kw):
        return f"[{fn(*a, **kw)}]"
    return wrapper

def excited(fn):
    @wraps(fn)
    def wrapper(*a, **kw):
        return f"{fn(*a, **kw)}!"
    return wrapper

@bracketed
@excited
def greet(name):
    return f"hello {name}"

# Equivalent to: greet = bracketed(excited(greet))
print(greet("Ada"))
`}
/>

## Built-in decorators worth knowing

- `@staticmethod`, `@classmethod`, `@property` (in classes)
- `@functools.cache` and `@functools.lru_cache` for memoization
- `@functools.wraps` (inside your own decorators)
- `@dataclass` (covered in *Classes*)

<CodeBlock
  adapter="python"
  initialCode={`from functools import cache

@cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(100))
`}
/>

Without `@cache`, computing `fib(100)` recursively would take longer
than the heat death of the universe. With it, the answer is instant
because each call is memoized.

## `@property`

`@property` turns a method into a read-only attribute. Pair it with a
setter to control writes.

<CodeBlock
  adapter="python"
  initialCode={`class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("below absolute zero")
        self._celsius = value

    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

t = Temperature(20)
print(t.celsius, t.fahrenheit)
t.celsius = 100
print(t.fahrenheit)
try:
    t.celsius = -500
except ValueError as e:
    print("ValueError:", e)
`}
/>

`bool` has exactly two values: `True` and `False`. Both are written
capitalized, and both are singleton objects.

<CodeBlock
  adapter="python"
  initialCode={`print(type(True))
print(True == 1, False == 0)        # bool is a subclass of int
print(True + True + True)           # 3
`}
/>

## Comparison operators

| Operator | Meaning |
| --- | --- |
| `==`, `!=` | value equality / inequality |
| `<`, `<=`, `>`, `>=` | ordering |
| `is`, `is not` | identity (same object?) |
| `in`, `not in` | membership in a sequence/container |

<CodeBlock
  adapter="python"
  initialCode={`print(3 < 5 <= 5)            # chained comparisons! Same as 3 < 5 and 5 <= 5
print("a" in "banana")
print(2 in [1, 2, 3])
print(None is None)
`}
/>

### `==` vs `is`

`==` asks "are these equal?". `is` asks "are these the *same* object?".
For singletons like `None`, `True`, `False`, always use `is`.

<CodeBlock
  adapter="python"
  initialCode={`a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True, same contents
print(a is b)   # False, different list objects

x = None
print(x is None)   # the idiomatic check
`}
/>

## Truthiness

Any object can be tested in a boolean context. The rules:

- **Falsy:** `False`, `None`, any zero (`0`, `0.0`, `0j`), any empty
  container (`""`, `[]`, `()`, `{}`, `set()`), and instances of
  classes that define `__bool__` to return `False`.
- **Truthy:** everything else.

<CodeBlock
  adapter="python"
  initialCode={`for value in [0, 1, "", "hi", [], [0], None, {0: 0}, {}]:
    print(f"{value!r:>10} -> {bool(value)}")
`}
/>

This is why idiomatic Python writes `if items:` rather than
`if len(items) > 0:`.

## Logical operators

`and`, `or`, `not` are written as English words, not symbols. They
**short-circuit**, returning one of the operands rather than a
strict `True`/`False`.

<CodeBlock
  adapter="python"
  initialCode={`print(True and "hello")   # 'hello' (and returns the last truthy / first falsy)
print(False or "default") # 'default'
print(None or 0 or "first truthy")
print(not 0)
`}
/>

A common idiom uses `or` to supply a default:

<CodeBlock
  adapter="python"
  initialCode={`name = ""
print(name or "Anonymous")    # "Anonymous"

# Careful: 0 is falsy, so 'or' replaces it. Use a None check instead.
count = 0
print(count or 10)            # 10, probably not what you want!
print(count if count is not None else 10)  # 0
`}
/>

## Conditional expressions

The ternary form puts the condition in the middle:

<CodeBlock
  adapter="python"
  initialCode={`age = 17
status = "adult" if age >= 18 else "minor"
print(status)
`}
/>

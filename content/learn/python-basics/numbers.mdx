Python ships with three numeric types and a comfortable set of
operators. Integers are arbitrary-precision, floats are IEEE 754
doubles, and complex numbers use a `j` suffix.

## Integers

`int` has no fixed size: it grows to fit whatever value you give it.

<CodeBlock
  adapter="python"
  initialCode={`big = 2 ** 200
print(big)
print("digits:", len(str(big)))
`}
/>

Integer literals support several bases:

<CodeBlock
  adapter="python"
  initialCode={`print(0b1010)   # binary -> 10
print(0o17)     # octal  -> 15
print(0xff)     # hex    -> 255

# Underscores are allowed for readability (Python 3.6+).
print(1_000_000)
`}
/>

## Floats

`float` is a 64-bit IEEE 754 double. That means it has the usual
precision quirks:

<CodeBlock
  adapter="python"
  initialCode={`print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)

# Use math.isclose for safe float equality.
import math
print(math.isclose(0.1 + 0.2, 0.3))
`}
/>

For exact decimal arithmetic (money!), use `decimal.Decimal`:

<CodeBlock
  adapter="python"
  initialCode={`from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))
`}
/>

## Arithmetic operators

| Operator | Meaning | Example |
| --- | --- | --- |
| `+` | addition | `2 + 3 == 5` |
| `-` | subtraction | `5 - 2 == 3` |
| `*` | multiplication | `2 * 3 == 6` |
| `/` | true division | `7 / 2 == 3.5` |
| `//` | floor division | `7 // 2 == 3` |
| `%` | modulo | `7 % 2 == 1` |
| `**` | exponentiation | `2 ** 10 == 1024` |

A common surprise: `/` always returns a float in Python 3, even when
both operands are integers. Use `//` if you want integer division.

<CodeBlock
  adapter="python"
  initialCode={`print(7 / 2)
print(7 // 2)
print(-7 // 2)   # floor division rounds toward negative infinity
print(7 % 2)
print(2 ** 0.5) # square root via exponentiation
`}
/>

## Augmented assignment

`x += 1`, `x *= 2`, `x //= 3`, and so on are all available.

## The `math` module

`math` is in the standard library. It covers the usual suspects:

<CodeBlock
  adapter="python"
  initialCode={`import math

print(math.pi, math.e)
print(math.sqrt(2))
print(math.sin(math.pi / 2))
print(math.log(100, 10))
print(math.factorial(6))
print(math.gcd(24, 36))
print(math.floor(3.7), math.ceil(3.2), round(3.5))
`}
/>

Note that `round` uses *banker's rounding* (round half to even), which
sometimes surprises people:

<CodeBlock
  adapter="python"
  initialCode={`print(round(0.5))   # 0, not 1
print(round(1.5))   # 2
print(round(2.5))   # 2, not 3
`}
/>

## Random numbers

For non-cryptographic randomness, use `random`. For cryptography use
`secrets` instead.

<CodeBlock
  adapter="python"
  initialCode={`import random
random.seed(42)  # makes output reproducible

print(random.random())            # float in [0.0, 1.0)
print(random.randint(1, 6))       # inclusive on both ends
print(random.choice(["a", "b", "c"]))
print(random.sample(range(100), 5))
`}
/>

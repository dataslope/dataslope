A `list` is an ordered, mutable sequence that can hold values of any
type. Lists are the workhorse collection in Python.

## Indexing and slicing

Lists support the same `[i]` and `[start:stop:step]` syntax as
strings. Unlike strings, you can assign through them.

<CodeBlock
  adapter="python"
  initialCode={`xs = [10, 20, 30, 40, 50]
print(xs[0], xs[-1])
print(xs[1:4])
print(xs[::-1])

xs[0] = 99
xs[1:3] = ["a", "b", "c"]   # slice assignment can resize the list
print(xs)
`}
/>

## Common methods

| Method | What it does |
| --- | --- |
| `append(x)` | add x to the end |
| `extend(iterable)` | append every item from another iterable |
| `insert(i, x)` | insert x at index i |
| `remove(x)` | remove first occurrence of x, raises if missing |
| `pop([i])` | remove and return item at index i (default last) |
| `clear()` | empty the list |
| `index(x)` | first index of x |
| `count(x)` | how many times x appears |
| `sort(key=, reverse=)` | sort in place |
| `reverse()` | reverse in place |
| `copy()` | shallow copy |

<CodeBlock
  adapter="python"
  initialCode={`xs = [3, 1, 4, 1, 5, 9, 2, 6]
xs.append(99)
xs.extend([7, 8])
xs.insert(0, "start")
xs.remove(1)        # removes the first 1
last = xs.pop()
print("xs:", xs)
print("popped:", last)

# Sorting
nums = [3, 1, 4, 1, 5, 9, 2, 6]
nums.sort()
print("sorted in place:", nums)

words = ["banana", "Apple", "cherry"]
words.sort(key=str.lower)
print("sorted case-insensitive:", words)

# sorted() returns a new list and leaves the original alone.
print(sorted([3, 1, 2]))
`}
/>

## Iteration

<CodeBlock

  initialCode={`fruits = ["apple", "banana", "cherry"]

    print(fruit)

# When you also need the index, use enumerate.

    print(i, fruit)

# Iterate two lists in lockstep with zip.

`}

## Copying gotcha

`b = a` does **not** copy. Use one of these instead:

<CodeBlock
  adapter="python"
  initialCode={`a = [1, [2, 3]]
b = a.copy()          # shallow copy
b[0] = 99
print(a, b)

# Shallow means the inner list is shared!
b[1].append(4)
print(a, b)

# For independent nested data, use copy.deepcopy
import copy
c = copy.deepcopy(a)
c[1].append(99)
print(a, c)
`}
/>

## Stacks and queues

Python lists make excellent stacks (`append`/`pop` are O(1) at the
end). For queues, prefer `collections.deque`, which is O(1) at both
ends.

<CodeBlock
  adapter="python"
  initialCode={`stack = []
stack.append("a")
stack.append("b")
stack.append("c")
print(stack.pop())   # 'c'
print(stack)

from collections import deque
q = deque(["a", "b", "c"])
q.append("d")        # enqueue right
print(q.popleft())   # dequeue left -> 'a'
print(q)
`}
/>

<ChallengeCard
  adapter="python"
  title="Remove duplicates, preserving order"
  instructions={`Define \`dedupe(items)\` that returns a list of the items in \`items\` with duplicates removed, keeping the **first** occurrence of each. For example, \`dedupe([3, 1, 3, 2, 1, 4])\` returns \`[3, 1, 2, 4]\`.

  initialCode={`def dedupe(items):

    return []
`}
  solutionCode={`def dedupe(items):
    seen = set()
    out = []
    for x in items:
        if x not in seen:
            seen.add(x)
            out.append(x)
    return out
`}
  tests={[

      code: `assert dedupe(["a", "a", "a"]) == ["a"]`,
    },
    {

      name: "Empty list",

Welcome to **Python Basics**. This course takes you from your very first
`print("hello")` all the way to writing your own classes, generators, and
decorators. By the end you will be comfortable enough with the language to
move on to data science, web frameworks, automation, or whatever pulls you in
next.

There is one thing to get out of the way before anything else: **this whole
course runs in your browser.** You do not have to install Python. You do not
have to set up an editor, a terminal, or a single configuration file. The code
blocks on every page are not screenshots — they are live programs you can run
and change.

So let's not talk about it. Let's run something.

## How each page works

Each page mixes plain-English explanation with three kinds of interactive
widgets:

1. **Runnable code blocks.** Every snippet runs in your browser. Edit any block
   and click *Run* to see the result. Each block starts in a fresh Python
   scope, so a variable defined in one block is not visible in the next. This
   keeps examples isolated and easy to reason about. If you want a longer-lived
   scratchpad, open the [Python Playground](/playground/python) in a new tab.
2. **Challenge cards.** Small coding problems with automatic test cases. A few
   use multiple files so you can practice importing across modules.
3. **Multiple choice questions.** Quick checks at the end of most pages. Every
   choice has its own explanation, so a wrong answer is still a chance to learn
   something.

## What you will learn

The course is one long, readable arc, designed to be read in order — though
each page also stands on its own if you want to jump around.

We start with the absolute basics: running code, the rule about indentation
that makes Python look the way it does, and the idea that a variable is a
**label on a value**, not a box. From there we tour Python's built-in types —
numbers, text, booleans — and its collections: lists, tuples, dictionaries, and
sets. Along the way we slow down on the parts beginners genuinely trip over,
like the difference between changing an object and rebinding a name.

Then we get to the verbs of programming: making decisions with conditionals,
repeating work with loops, and the elegant comprehension shortcuts that make
Python so concise. We define our own functions, learn the surprisingly subtle
rules of **scope**, and organize code into modules. We handle errors
gracefully, read and write files, and then climb into object-oriented
Python — classes, inheritance, and the trio of features where Python's
flexibility really shines: **iterators, generators, and decorators**.

The final stretch covers virtual environments and `pip` for when you do want to
run Python locally, an optional deep-dive into **the story of Python** — where
it came from, why it makes indentation part of the syntax, and the debates that
shaped it — and a map of where to go next.

Learning to program is unlike learning most other things. You will get stuck.
You will type the wrong character and stare at code that "should" work while it
stubbornly does not. That is completely normal — it is, in fact, the whole
skill. Read carefully, *type the examples yourself*, try the challenges, and
understanding will sneak up on you.

Ready? Turn the page and write your first real program.

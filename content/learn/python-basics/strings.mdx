A `str` in Python 3 is an immutable sequence of Unicode code points.
It is one of the most-used types in the language and has a rich
toolkit attached to it.

## String literals

There are four ways to write a string literal, and they are all
equivalent at the value level.

<CodeBlock
  adapter="python"
  initialCode={`a = 'single quotes'
b = "double quotes"
c = """triple-quoted
spans multiple
lines"""
d = '''also triple-quoted'''

print(a, b, c, d, sep="\\n---\\n")
`}
/>

Python is happy to use either quote style. Pick whichever lets you
avoid backslash escapes for the quote character itself.

### Escape sequences

| Sequence | Meaning |
| --- | --- |
| `\\n` | newline |
| `\\t` | tab |
| `\\\\` | backslash |
| `\\'`, `\\"` | quote of that kind |
| `\\u00e9` | Unicode code point (here, `é`) |
| `\\xff` | hex byte |

### Raw strings

Prefix a literal with `r` to disable escape processing. Useful for
regex patterns and Windows paths.

<CodeBlock
  adapter="python"
  initialCode={`print("C:\\nope")     # \\n is a newline
print(r"C:\\nope")    # raw, the backslash is literal
`}
/>

## Indexing and slicing

Strings are sequences, so they support indexing (`s[i]`) and slicing
(`s[start:stop:step]`). Indices are zero-based; negative indices count
from the end.

<CodeBlock
  adapter="python"
  initialCode={`s = "Python"
print(s[0])     # 'P'
print(s[-1])    # 'n'
print(s[1:4])   # 'yth'
print(s[:2])    # 'Py'
print(s[2:])    # 'thon'
print(s[::-1])  # 'nohtyP'
`}
/>

Slicing **never raises `IndexError`**, even with out-of-range bounds.
It just returns whatever overlaps.

## Strings are immutable

You cannot mutate a string in place. Methods like `upper`, `replace`,
and `strip` return new strings.

<CodeBlock
  adapter="python"
  initialCode={`s = "hello"
try:
    s[0] = "H"
except TypeError as e:
    print("TypeError:", e)

print(s.upper())
print(s)   # unchanged
`}
/>

## Common methods

A small selection of methods you will use constantly:

<CodeBlock
  adapter="python"
  initialCode={`s = "  Hello, World!  "

print(s.strip())
print(s.lower())
print(s.upper())
print(s.replace("World", "Python"))
print(s.split(","))
print("-".join(["a", "b", "c"]))
print("hello".startswith("he"))
print("hello".endswith("lo"))
print("hello".find("l"))    # 2 (first index) or -1 if not found
print("hello".count("l"))   # 2
print("42".isdigit())
print("Hello".isalpha())
`}
/>

## Formatting: f-strings (3.6+)

The modern, recommended way to build a string. Put any expression
inside `{ ... }`.

<CodeBlock
  adapter="python"
  initialCode={`name = "Ada"
score = 87.4321

print(f"{name} scored {score}")
print(f"{name} scored {score:.1f}")          # one decimal place
print(f"{name:>10} | {score:>6.2f}")         # right-aligned, widths
print(f"{score:,.2f}")                       # thousands separator
print(f"{score=}")                           # debug form (3.8+)

# Expressions are fine inside the braces.
print(f"double = {score * 2:.2f}")
`}
/>

Other formatting styles you will see in older code:

<CodeBlock
  adapter="python"
  initialCode={`name = "Ada"
score = 87.4

# str.format (Python 3.0+)
print("{} scored {:.1f}".format(name, score))

# Old % formatting (still works, ported from C printf)
print("%s scored %.1f" % (name, score))
`}
/>

## Concatenation and repetition

<CodeBlock
  adapter="python"
  initialCode={`print("foo" + "bar")
print("ab" * 3)
print("-" * 20)

# Building a string by repeated +=ing is O(n^2). For loops, use ''.join.
parts = []
for i in range(5):
    parts.append(str(i))
print("".join(parts))
`}
/>

## Bytes vs strings

`str` holds Unicode code points; `bytes` holds raw 8-bit values. Use
`.encode()` to go from `str` to `bytes` and `.decode()` to go back.
The default codec is UTF-8.

<CodeBlock
  adapter="python"
  initialCode={`s = "café"
b = s.encode("utf-8")
print(b, len(b), len(s))
print(b.decode("utf-8"))
`}
/>

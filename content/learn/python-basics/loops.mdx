Python has two looping constructs: `for` and `while`. `for` iterates
over any iterable; `while` repeats while a condition holds true.

## The `for` loop

<CodeBlock
  adapter="python"
  initialCode={`for fruit in ["apple", "banana", "cherry"]:
    print(fruit)
`}
/>

`for` works on any iterable: lists, tuples, strings, sets, dicts,
files, generators, and your own custom classes (covered later under
*Iterators and Generators*).

## `range`

`range(stop)`, `range(start, stop)`, and `range(start, stop, step)` produce
arithmetic progressions lazily. They are the canonical way to loop
"N times".

<CodeBlock
  adapter="python"
  initialCode={`for i in range(5):
    print(i, end=" ")
print()

for i in range(1, 6):
    print(i, end=" ")
print()

for i in range(0, 20, 5):
    print(i, end=" ")
print()

for i in range(10, 0, -2):
    print(i, end=" ")
print()
`}
/>

## `enumerate`, `zip`, `reversed`

If your loop needs the index, do **not** write `range(len(xs))`. Use
`enumerate`.

<CodeBlock
  adapter="python"
  initialCode={`fruits = ["apple", "banana", "cherry"]

for i, fruit in enumerate(fruits, start=1):
    print(i, fruit)

prices = [1.0, 0.5, 3.0]
for fruit, price in zip(fruits, prices):
    print(f"{fruit}: \${price}")

for fruit in reversed(fruits):
    print(fruit)
`}
/>

## The `while` loop

<CodeBlock
  adapter="python"
  initialCode={`n = 16
steps = 0
while n != 1:
    n = n // 2 if n % 2 == 0 else 3 * n + 1
    steps += 1
print("steps:", steps)
`}
/>

Use `while True` plus `break` for "loop until something happens" code
where the loop body is what knows when to stop.

<CodeBlock
  adapter="python"
  initialCode={`from itertools import count

for n in count(1):
    if n * n > 100:
        print("first square over 100 is", n * n)
        break
`}
/>

## `break` and `continue`

- `break` exits the *innermost* loop immediately.
- `continue` skips the rest of the current iteration and goes back to
  the top.

<CodeBlock
  adapter="python"
  initialCode={`for n in range(1, 11):
    if n == 7:
        print("found 7, stopping")
        break
    if n % 2 == 0:
        continue
    print("odd:", n)
`}
/>

## `else` on a loop (the weird one)

Both `for` and `while` accept an `else:` block, which runs **only if
the loop completed normally** (no `break`). It is most useful for
search loops:

<CodeBlock
  adapter="python"
  initialCode={`def first_factor(n):
    for i in range(2, n):
        if n % i == 0:
            print(f"{n} = {i} * {n // i}")
            break
    else:
        print(f"{n} is prime")

for n in [12, 13, 21, 29]:
    first_factor(n)
`}
/>

This pattern is rare but worth recognizing when you see it.

## Avoiding common pitfalls

- **Modifying a list while iterating over it** invalidates the
  iterator. Iterate over a copy or build a new list.
- **Off-by-one errors** are common with `range`. Remember the upper
  bound is exclusive: `range(5)` yields 0, 1, 2, 3, 4.
- **`for else` does not fire if you `break`.** That is the whole
  point, but it surprises people.

<CodeBlock
  adapter="python"
  initialCode={`# Removing items while iterating: BAD.
xs = [1, 2, 3, 4, 5]
for x in xs[:]:               # iterate over a copy
    if x % 2 == 0:
        xs.remove(x)
print(xs)
`}
/>

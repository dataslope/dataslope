title: Dictionaries

A `dict` maps **keys** to **values**. Lookups, insertions, and
deletions are all average-case O(1). Dictionaries are everywhere in
Python: JSON, function keyword arguments, object attributes, and many
config formats are all dict-shaped.

## Creating dicts

<CodeBlock
  adapter="python"
  initialCode={`empty = {}
person = {"name": "Ada", "year": 1815}
also_person = dict(name="Ada", year=1815)
from_pairs = dict([("a", 1), ("b", 2)])

print(also_person)

`}

## Accessing values

<CodeBlock
  adapter="python"
  initialCode={`person = {"name": "Ada", "year": 1815}

print(person["name"])

# Missing key with [] raises KeyError.
try:
    print(person["email"])
except KeyError as e:
    print("missing:", e)

# .get returns None (or your default) instead of raising.
print(person.get("email"))
print(person.get("email", "no email on file"))
`}
/>

## Iterating

<CodeBlock
  adapter="python"
  initialCode={`prices = {"apple": 1.0, "banana": 0.5, "cherry": 3.0}

# By default, iteration yields keys.
for fruit in prices:
    print(fruit)

# Items gives (key, value) pairs.
for fruit, price in prices.items():
    print(f"{fruit}: \${price:.2f}")

# Values alone.
print(list(prices.values()))
`}
/>

## Insertion order is preserved

Since Python 3.7, `dict` officially preserves insertion order. The
first item you put in is the first one you see when iterating.

<CodeBlock
  adapter="python"
  initialCode={`d = {}
for k in "python":
    d[k] = k.upper()
print(d)
`}
/>

## Keys must be hashable

Strings, numbers, booleans, frozensets, and tuples-of-hashables work.
Lists, sets, and dicts do not.

<CodeBlock
  adapter="python"
  initialCode={`good = {("x", 1): "ok"}
print(good)

try:
    bad = {[1, 2]: "nope"}
except TypeError as e:
    print("TypeError:", e)
`}
/>

## Merging dicts (Python 3.9+)

<CodeBlock
  adapter="python"
  initialCode={`a = {"x": 1, "y": 2}
b = {"y": 99, "z": 3}

# | creates a new dict, right operand wins on conflicts.
print(a | b)

# |= mutates in place.
a |= b
print(a)
`}
/>

## Counting and grouping

`collections.Counter` and `collections.defaultdict` cover two of the
most common dict patterns.

<CodeBlock
  adapter="python"
  initialCode={`from collections import Counter, defaultdict

# Count word frequencies.
text = "to be or not to be that is the question to be"
print(Counter(text.split()))
print(Counter(text.split()).most_common(3))

# Group items by first letter.
words = ["apple", "ant", "banana", "berry", "cherry"]
groups = defaultdict(list)
for w in words:
    groups[w[0]].append(w)
print(dict(groups))
`}
/>

## JSON

Dicts and JSON objects share a syntax for a reason. The `json` module
converts both ways:

<CodeBlock
  adapter="python"
  initialCode={`import json

person = {"name": "Ada", "year": 1815, "skills": ["math", "logic"]}
text = json.dumps(person, indent=2)
print(text)

restored = json.loads(text)
print(restored, restored == person)
`}
/>

    freq = {}
    for word in sentence.lower().split():
        freq[word] = freq.get(word, 0) + 1
    return freq

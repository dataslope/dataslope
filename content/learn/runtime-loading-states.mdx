## Overview

The first time a learner runs code on a page, the language runtime (Pyodide, WebR, CheerpJ, .NET, the clang toolchain…) has to download and instantiate — a multi-second wait on a cold cache. The **runtime boot notice** turns that wait into something legible: the brand **assemble-and-quarter-turn** mark, the current setup stage, a one-time size hint, and a determinate progress bar.

It is one shared component, [`<RuntimeBootNotice>`](https://github.com/dataslope/dataslope/blob/main/app/_components/RuntimeBootNotice.tsx), rendered by both `<CodeBlock>` and `<ChallengeCard>` while their runtime is `loading`. The bar is driven by coarse **stage fractions** each adapter reports through the runtime registry; between stages a smoothing hook eases it forward so it never looks frozen, and it deliberately never reaches 100% — the notice unmounts the instant the runtime is ready.

A stdlib-only snippet runs the moment the interpreter is ready (Python's two-phase boot doesn't wait for the data stack):

## Using the component

`<RuntimeBootNotice>` is presentational and self-contained (it carries its own theme tokens), so it renders correctly embedded in a block or standalone:

```tsx
import { RuntimeBootNotice } from "@/app/_components/RuntimeBootNotice";

<RuntimeBootNotice
  language="Python"
  statusMessage="Loading Pyodide…"  // current stage from the adapter
  cold                              // first-run download in flight
  downloadMB={6}                    // adapter.coldDownloadMB
  fraction={0.42}                   // smoothed 0..1, or null = indeterminate
/>;
```

| Prop | Meaning |
| --- | --- |
| `language` | Display name used in the copy (e.g. "Python"). |
| `statusMessage` | Current setup stage; falls back to "Setting up the … runtime…". |
| `cold` | When true, shows the size hint and the "happens once" reassurance. |
| `downloadMB` | Approximate first-run download size in MB. |
| `fraction` | Smoothed boot fraction `0..1`; `null` renders the loader and copy with no bar. |

The brand loader itself is [`<DiamondAssembleTurnLoader>`](/learn/loading-animations) — see the Loading Animations page for the full set of brand spinners and the wave.

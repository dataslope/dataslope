## Overview

The first time a learner runs code on a page, the language runtime (Pyodide, WebR, CheerpJ, .NET, the clang toolchain…) has to download and instantiate — a multi-second wait on a cold cache. The **runtime boot notice** turns that wait into something legible: the brand **assemble-and-quarter-turn** mark, the current setup stage, a one-time size hint, and a determinate progress bar.

It is one shared component, [`<RuntimeBootNotice>`](https://github.com/dataslope/dataslope/blob/main/app/_components/RuntimeBootNotice.tsx), rendered by both `<CodeBlock>` and `<ChallengeCard>` in their output panel while the runtime is `loading`. The bar is driven by coarse **stage fractions** each adapter reports through the runtime registry; between stages a smoothing hook eases it forward so it never looks frozen, and it deliberately never reaches 100% — the notice unmounts the instant the runtime is ready.

> **Why you rarely see this on a real lesson:** every block warms its runtime in the background as soon as the page lands (idle-scheduled, one boot at a time, skipped on Save-Data). By the time you finish reading and click **Run**, the runtime is usually already warm, so the boot is instant. The previews below are static (no runtime) so the loading display can be reviewed on demand.

## Using the components

Both pieces are presentational and self-contained (they carry their own theme tokens), so they render correctly embedded in a block or standalone:

```tsx
import {
  RuntimeBootNotice,
  CodeBlockLoadingPreview,
} from "@/app/_components/RuntimeBootNotice";

// Just the notice (what the output panel renders while loading):
<RuntimeBootNotice
  language="Python"
  statusMessage="Loading Pyodide…"  // current stage from the adapter
  cold                              // first-run download in flight
  downloadMB={6}                    // adapter.coldDownloadMB
  fraction={0.42}                   // smoothed 0..1, or null = indeterminate
/>;

// The whole code-block layout, frozen loading (static preview, no runtime):
<CodeBlockLoadingPreview
  language="Python"
  version="3.13.2"
  code={`import pandas as pd\n# …`}
  statusMessage="Loading Pyodide…"
  cold
  downloadMB={6}
  fraction={0.42}
/>;
```

| Prop | Meaning |
| --- | --- |
| `language` | Display name used in the copy (e.g. "Python"). |
| `statusMessage` | Current setup stage; falls back to "Setting up the … runtime…". |
| `cold` | When true, shows the size hint and the "happens once" reassurance. |
| `downloadMB` | Approximate first-run download size in MB. |
| `fraction` | Smoothed boot fraction `0..1`; `null` renders the loader and copy with no bar. |

`<CodeBlockLoadingPreview>` adds `version`, `langId` (for the header glyph), and `code` (the faux editor contents) on top of those.

The brand loader itself is [`<DiamondAssembleTurnLoader>`](/learn/loading-animations) — see the Loading Animations page for the full set of brand spinners and the wave.

R challenges run via **WebR** in your browser. The harness uses
`tryCatch` to frame each test result and `jsonlite::toJSON` to
serialise failure messages.

## 1. Vector arithmetic

<ChallengeCard
  adapter="r"
  title="Mean, median, sd"
  instructions={`Define three variables — \`m\`, \`md\`, and \`s\` — holding the mean, median, and standard deviation of the vector \`x\`.`}
  initCode={`x <- c(2, 4, 4, 4, 5, 5, 7, 9)`}
  initialCode={`m  <- NA
md <- NA
s  <- NA

cat("mean:", m, "median:", md, "sd:", s, "\\n")
`}
  solutionCode={`x <- c(2, 4, 4, 4, 5, 5, 7, 9)
cat("mean:",   mean(x),   "\\n")
cat("median:", median(x), "\\n")
cat("sd:",     sd(x),     "\\n")
`}
  tests={[
    {
      id: "mean",
      name: "Mean is correct",
      description: "mean(x) = 5",
      code: `if (!isTRUE(all.equal(m, 5))) stop(sprintf("expected mean 5, got %s", m))`,
    },
    {
      id: "median",
      name: "Median is correct",
      description: "median(x) = 4.5",
      code: `if (!isTRUE(all.equal(md, 4.5))) stop(sprintf("expected median 4.5, got %s", md))`,
    },
    {
      id: "sd",
      name: "Standard deviation is correct",
      description: "sd(x) ≈ 2.138",
      code: `if (!isTRUE(all.equal(s, sd(c(2,4,4,4,5,5,7,9))))) stop("sd mismatch")`,
    },
  ]}
/>

## 2. Data frame slicing

<ChallengeCard
  adapter="r"
  title="Filter a data frame"
  instructions={`Build a data frame called \`filtered\` containing only the rows of \`df\` where \`score >= 80\`.`}
  initCode={`df <- data.frame(
  name  = c("Ada", "Linus", "Grace", "Alan"),
  score = c(92, 88, 75, 81),
  stringsAsFactors = FALSE
)`}
  initialCode={`filtered <- NULL # TODO

print(filtered)
`}
  solutionCode={`df <- data.frame(
  name  = c("Ada", "Linus", "Grace", "Alan"),
  score = c(95, 70, 88, 60)
)
high <- df[df$score >= 80, ]
print(high)
`}
  tests={[
    {
      id: "is_df",
      name: "filtered is a data frame",
      description: "Should be a data.frame instance",
      code: `if (!is.data.frame(filtered)) stop("filtered must be a data.frame")`,
    },
    {
      id: "row_count",
      name: "3 rows after filtering",
      description: "Ada, Linus, Alan should remain",
      code: `if (nrow(filtered) != 3) stop(sprintf("expected 3 rows, got %d", nrow(filtered)))`,
    },
    {
      id: "no_grace",
      name: "Grace was excluded",
      description: "score 75 is below the cutoff",
      code: `if ("Grace" %in% filtered$name) stop("Grace should be excluded")`,
    },
  ]}
/>

## Multi-file challenge

Multi-file challenges open with a non-sortable, non-closeable tab bar
above the editor. Every file is staged into WebR's virtual filesystem
before each run, so the entry script can `source()` sibling files.

<ChallengeCard
  adapter="r"
  title="Implement greet() in utils.R"
  instructions={`Open \`utils.R\` and implement \`greet(name)\` so that it returns the string \`"Hello, <name>!"\`. The entry script \`main.R\` already sources your file and prints the result.`}
  entryFilename="main.R"
  files={[
    {
      filename: "main.R",
      initialContent: `source("utils.R")\ncat(greet("World"))\n`,
    },
    {
      filename: "utils.R",
      initialContent: `greet <- function(name) {\n  # your code here\n  ""\n}\n`,
    },
  ]}
  solutionCode={`greet <- function(name) {\n  paste0("Hello, ", name, "!")\n}\n`}
  tests={[
    {
      id: "greets",
      name: "Prints `Hello, World!`",
      description: "main runs and greet returns the expected value",
      code: `stopifnot(greet("World") == "Hello, World!")`,
    },
  ]}
/>

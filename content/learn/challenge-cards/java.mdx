Java challenges compile in the browser via **CheerpJ** (an
in-browser OpenJDK). Tests use the stdout-based mode because the JVM
process exits after `main` returns.

The class name in your source must match the filename CheerpJ derives
from it. Keep the class named `Main` for these exercises.

## 2. String manipulation

<ChallengeCard
  adapter="java"
  title="Reverse a String"
  instructions={`Reverse the string \`"DataSlope"\` and print it on its own line.`}
  initialCode={`public class Main {
    public static void main(String[] args) {
        String s = "DataSlope";
        // your code here
    }
}
`}
  solutionCode={`public class Main {
    public static String reverse(String s) {
        return new StringBuilder(s).reverse().toString();
    }
    public static void main(String[] args) {
        System.out.println(reverse("hello"));
        System.out.println(reverse("racecar"));
    }
}
`}
  tests={[
    {
      id: "reversed",
      name: "Prints reversed string",
      description: "Output: `epolSataD`",
      expect: { stdoutEquals: "epolSataD" },
    },
  ]}
/>

## 3. Multi-file challenge

Multi-file challenges open with a non-sortable, non-closeable tab bar
above the editor. Click a filename to switch buffers. Every file in the
workspace is staged into CheerpJ's virtual filesystem before each run,
so `Main` can reference `Dog` directly without any imports.

<ChallengeCard
  adapter="java"
  title="Implement Dog.bark()"
  instructions={`Open \`Dog.java\` and implement the \`bark()\` method so that it returns the string \`"Woof!"\`. \`Main.java\` is provided — it constructs a \`Dog\` and prints the result of \`bark()\`.`}
  entryFilename="Main.java"
  files={[
    {
      filename: "Main.java",
      initialContent: `public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        System.out.println(d.bark());
    }
}
`,
    },
    {
      filename: "Dog.java",
      initialContent: `public class Dog {
    public String bark() {
        // your code here
        return "";
    }
}
`,
      solutionContent: `public class Dog {
    public String bark() {
        return "Woof!";
    }
}
`,
    },
  ]}
  tests={[
    {
      id: "barks",
      name: "Prints `Woof!`",
      description: "Main runs and bark() returns the expected value",
      expect: { stdoutEquals: "Woof!" },
    },
  ]}
/>

## 4. Loops and conditionals

<ChallengeCard
  adapter="java"
  title="Print even numbers"
  instructions={`Print every even number from **2** to **10** (inclusive), one per line.`}
  initialCode={`public class Main {
    public static void main(String[] args) {
        // your code here
    }
}
`}
  solutionCode={`public class Main {
    public static void main(String[] args) {
        for (int i = 2; i <= 10; i += 2) {
            System.out.println(i);
        }
    }
}
`}
  tests={[
    {
      id: "evens",
      name: "Prints 2, 4, 6, 8, 10",
      description: "Five lines, one per even number",
      expect: {
        stdoutLines: ["2", "4", "6", "8", "10"],
        stdoutLinesExact: true,
      },
    },
  ]}
/>

---
title: Code Blocks — Initialization Code
description: Executable code blocks that use read-only initialization code, demonstrated for every language alongside the raw JSX.
---

Every executable `CodeBlock` accepts an optional **`initCode`** prop: read-only
setup code shown in a collapsible panel above the editor and prepended to your
snippet on every Run. It's handy for imports, sample data, or helper
definitions you want available without cluttering the part the learner edits.

The init code is prepended *verbatim*, so it must be valid at the **top level**
of the target language (e.g. `import` / `#include` / `using` directives, or a
complete declaration the snippet can reference). Each example below shows the
live, runnable code block followed by the exact JSX you would author in MDX.

## Python

<CodeBlock
  adapter="python"
  initCode={`import math

RADIUS = 5`}
  initialCode={`# RADIUS and math come from the initialization code above.
area = math.pi * RADIUS ** 2
print(f"A circle with r={RADIUS} has area {area:.2f}")
`}
/>

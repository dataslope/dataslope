C source is compiled to WebAssembly with **clang** (via `browsercc`)
and the resulting module is executed in your browser. The toolchain
downloads the first time you click Run.

## Working with arrays

<CodeBlock
  adapter="c"
  files={[
    {
      filename: "main.c",
      starterCode: `#include <stdio.h>

int main(void) {
  int xs[] = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3};
  int n = sizeof(xs) / sizeof(xs[0]);
  long sum = 0;
  for (int i = 0; i < n; i++)
    sum += xs[i];
  printf("n = %d, sum = %ld, mean = %.2f\\n", n, sum, (double)sum / n);
  return 0;
}
`,
    },
  ]}
/>

## Multiple files

Pass a `files` array alongside an `entryFilename` to compile a multi-translation-unit program. Header files in the workspace are visible to `#include "…"` directives and any other `.c` files are linked into the build.

<CodeBlock
  adapter="c"
  entryFilename="main.c"
  files={[
    {
      filename: "main.c",
      starterCode: `#include "mathx.h"
#include <stdio.h>

int main(void) {
  int a = 6, b = 7;
  printf("add(%d, %d) = %d\\n", a, b, add(a, b));
  printf("mul(%d, %d) = %d\\n", a, b, mul(a, b));
  return 0;
}
`,
    },
    {
      filename: "mathx.h",
      starterCode: `#ifndef MATHX_H
#define MATHX_H

int add(int a, int b);
int mul(int a, int b);

#endif
`,
    },
    {
      filename: "mathx.c",
      starterCode: `#include "mathx.h"

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }
`,
    },
  ]}
/>

## Initialization code

`initCode` is read-only setup prepended to your snippet on every Run, handy
for includes or helpers without cluttering the part you edit. Init of 3
lines or fewer shows a compact read-only header; 4 lines or more collapses
behind a "Click to expand" toggle.

A short init (3 lines or fewer):

<CodeBlock
  adapter="c"
  files={[
    {
      filename: "main.c",
      initCode: `#include <stdio.h>

#define GREETING "Hello from C!"`,
      starterCode: `/* GREETING and <stdio.h> come from the initialization code above. */
int main(void) {
  puts(GREETING);
  return 0;
}
`,
    },
  ]}
/>

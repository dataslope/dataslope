JavaScript runs directly in your browser, no WebAssembly runtime to
download. Each block is evaluated inside its own `AsyncFunction`
scope, so `let`/`const` declarations don't leak across blocks.

## Hello, world

<CodeBlock
  adapter="javascript"
  files={[
    {

console.log(greet("learner"));
console.log("π ≈", Math.PI.toFixed(4));
`,
    },
  ]}
/>

## Top-level await

User code is wrapped in an `async` function, so you can `await`
promises directly at the top level.

<CodeBlock
  adapter="javascript"
  files={[
    {
      filename: "main.js",
      starterCode: `const wait = (ms) => new Promise((r) => setTimeout(r, ms));
await wait(50);
console.log("Done waiting!");
`,
    },
  ]}
/>

## Multiple files

Use CommonJS `require("./module")` to pull in helpers defined in sibling files. The almostnode runtime mounts every workspace file at the project root so relative paths resolve as they would under Node.js.

<CodeBlock
  adapter="javascript"
  entryFilename="index.js"
  files={[
    {
      filename: "index.js",
      starterCode: `const { hello, bye } = require("./greetings");

console.log(hello("JavaScript Playground"));
console.log(bye("JavaScript Playground"));
`,
    },
    {
      filename: "greetings.js",
      starterCode: `function hello(name) {
  return \`Hello, \${name}!\`;
}

function bye(name) {
  return \`Goodbye, \${name}!\`;
}

module.exports = { hello, bye };
`,
    },
  ]}
/>

## Initialization code

`initCode` is read-only setup prepended to your snippet on every Run, handy
for imports or sample data without cluttering the part you edit. Init of 3
lines or fewer shows a compact read-only header; 4 lines or more collapses
behind a "Click to expand" toggle.

A short init (3 lines or fewer):

<CodeBlock
  adapter="javascript"
  files={[
    {
      filename: "main.js",
      initCode: `const greeting = "Hello";`,
      starterCode: `// 'greeting' comes from the initialization code above.
console.log(greeting + ", world!");
`,
    },
  ]}
/>

## 2. Containers and algorithms

<ChallengeCard
  adapter="cpp"
  title="Sort and print"
  instructions={`Given the integer vector below, sort it in ascending order and print each element on its own line.`}
  files={[
    {
      filename: "main.cpp",
      starterCode: `#include <algorithm>
#include <iostream>
#include <vector>

int main() {
  std::vector<int> xs = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3};
  // your code here
  return 0;
}
`,
      solutionCode: `#include <algorithm>
#include <iostream>
#include <vector>

int main() {
  std::vector<int> xs = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3};
  std::sort(xs.begin(), xs.end());
  for (int x : xs)
    std::cout << x << "\\n";
  return 0;
}
`,
    },
  ]}
  tests={[
    {
      id: "sorted",
      name: "Sorted ascending",
      description: "10 lines, sorted",
      expect: {
        stdoutLines: ["1", "1", "2", "3", "3", "4", "5", "5", "6", "9"],
        stdoutLinesExact: true,
      },
    },
  ]}
/>

## 3. Class definition (stdout)

<ChallengeCard
  adapter="cpp"
  title="Implement a Counter class"
  instructions={`Define a class \`Counter\` with a member function \`tick()\` that increments an internal counter and a \`value()\` method that returns its current value. The driver code in \`main\` will then print the counter after each tick.`}
  files={[
    {
      filename: "main.cpp",
      starterCode: `#include <iostream>

class Counter {
public:
  // your code here
};

int main() {
  Counter c;
  for (int i = 0; i < 3; i++) {
    c.tick();
    std::cout << c.value() << "\\n";
  }
  return 0;
}
`,
      solutionCode: `#include <iostream>

class Counter {
  int n = 0;

public:
  void tick() { ++n; }
  int value() const { return n; }
};

int main() {
  Counter c;
  for (int i = 0; i < 3; i++) {
    c.tick();
    std::cout << c.value() << "\\n";
  }
  return 0;
}
`,
    },
  ]}
  tests={[
    {
      id: "counts",
      name: "Counts 1, 2, 3",
      description: "Three ticks produce 1, 2, 3 on separate lines",
      expect: {
        stdoutLines: ["1", "2", "3"],
        stdoutLinesExact: true,
      },
    },
  ]}
/>

## Multi-file challenge

Multi-file challenges open with a non-sortable, non-closeable tab bar
above the editor. Every file is staged into browsercc's virtual
filesystem before each run, so the entry translation unit can
`#include` sibling headers.

<ChallengeCard
  adapter="cpp"
  title="Implement Greeter::greet()"
  instructions={`Open \`greeter.cpp\` and implement \`Greeter::greet()\` so that it prints \`Hello, World!\` followed by a newline. \`main.cpp\` is provided, it constructs a \`Greeter\` and calls \`greet()\`.`}
  entryFilename="main.cpp"
  files={[
    {
      filename: "main.cpp",
      starterCode: `#include "greeter.h"

int main() {
  Greeter g;
  g.greet();
  return 0;
}
`,
    },
    {
      filename: "greeter.h",
      starterCode: `#pragma once
class Greeter {
public:
  void greet();
};
`,
    },
    {
      filename: "greeter.cpp",
      starterCode: `#include "greeter.h"
#include <iostream>

void Greeter::greet() {
  // your code here
}
`,
      solutionCode: `#include "greeter.h"
#include <iostream>

void Greeter::greet() { std::cout << "Hello, World!\\n"; }
`,
    },
  ]}
  tests={[
    {
      id: "greets",
      name: "Prints `Hello, World!`",
      description: "Exact stdout match",
      expect: { stdoutEquals: "Hello, World!" },
    },
  ]}
/>

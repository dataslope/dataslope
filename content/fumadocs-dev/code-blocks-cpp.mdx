C++ source is compiled to WebAssembly with **clang++** (via
`browsercc`). Standard library headers like `<iostream>`, `<vector>`,
and `<algorithm>` are available.

## STL: vectors and algorithms

<CodeBlock
  adapter="cpp"
  files={[
    {
      filename: "main.cpp",
      starterCode: `#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
  std::vector<int> xs = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3};
  std::sort(xs.begin(), xs.end());
  int sum = std::accumulate(xs.begin(), xs.end(), 0);

  std::cout << "sorted:";
  for (int x : xs)
    std::cout << " " << x;
  std::cout << "\\nsum: " << sum << "\\n";
  return 0;
}
`,
    },
  ]}
/>

## Multiple files

Split a class into a header and an implementation file. Every workspace file is staged into the compiler's virtual file system so `#include "…"` directives resolve and additional `.cpp` files are linked into the final binary.

<CodeBlock
  adapter="cpp"
  entryFilename="main.cpp"
  files={[
    {
      filename: "main.cpp",
      starterCode: `#include "greeter.hpp"
#include <iostream>

int main() {
  Greeter g("C++ Playground");
  std::cout << g.hello() << "\\n";
  std::cout << g.bye() << "\\n";
  return 0;
}
`,
    },
    {
      filename: "greeter.hpp",
      starterCode: `#ifndef GREETER_HPP
#define GREETER_HPP

#include <string>

class Greeter {
public:
  explicit Greeter(std::string name);
  std::string hello() const;
  std::string bye() const;

private:
  std::string name_;
};

#endif
`,
    },
    {
      filename: "greeter.cpp",
      starterCode: `#include "greeter.hpp"

Greeter::Greeter(std::string name) : name_(std::move(name)) {}

std::string Greeter::hello() const { return "Hello, " + name_ + "!"; }
std::string Greeter::bye() const { return "Goodbye, " + name_ + "!"; }
`,
    },
  ]}
/>

## Initialization code

`initCode` is read-only setup prepended to your snippet on every Run, handy
for includes or helpers without cluttering the part you edit. Init of 3
lines or fewer shows a compact read-only header; 4 lines or more collapses
behind a "Click to expand" toggle.

A short init (3 lines or fewer):

<CodeBlock
  adapter="cpp"
  files={[
    {
      filename: "main.cpp",
      initCode: `#include <iostream>
using namespace std;`,
      starterCode: `// <iostream> and std come from the initialization code above.
int main() {
  cout << "Hello, C++!" << endl;
  return 0;
}
`,
    },
  ]}
/>

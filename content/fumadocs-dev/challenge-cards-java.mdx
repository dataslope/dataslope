Java challenges compile in the browser via **CheerpJ** (an
in-browser OpenJDK). Tests use the stdout-based mode because the JVM
process exits after `main` returns.

The class name in your source must match the filename CheerpJ derives
from it. Keep the class named `Main` for these exercises.

## 3. Multi-file challenge

Multi-file challenges open with a non-sortable, non-closeable tab bar
above the editor. Click a filename to switch buffers. Every file in the
workspace is staged into CheerpJ's virtual filesystem before each run,
so `Main` can reference `Dog` directly without any imports.

<ChallengeCard
  adapter="java"
  title="Implement Dog.bark()"
  instructions={`Open \`Dog.java\` and implement the \`bark()\` method so that it returns the string \`"Woof!"\`. \`Main.java\` is provided, it constructs a \`Dog\` and prints the result of \`bark()\`.`}
  entryFilename="Main.java"
  files={[
    {
      filename: "Main.java",
      starterCode: `public class Main {
  public static void main(String[] args) {
    Dog d = new Dog();
    System.out.println(d.bark());
  }
}
`,
    },
    {
      filename: "Dog.java",
      starterCode: `public class Dog {
  public String bark() {
    // your code here
    return "";
  }
}
`,

  public String bark() { return "Woof!"; }
}
`,

## Reading standard input

A card takes the same `stdin` prop. The panel is staged as `stdin.txt`
and opened as `System.in`, and the tests grade output produced from it.

<ChallengeCard
  adapter="java"
  title="Count the votes"
  stdin={`red
blue
red
green
red
blue`}
  instructions={`Each line of input is one vote. Print the winner and its count:

\`\`\`text
red wins with 3 votes
\`\`\``}
  files={[
    {
      filename: "main.java",
      starterCode: `import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    Scanner in = new Scanner(System.in);
    // tally the lines, then print the winner
  }
}
`,
      solutionCode: `import java.util.LinkedHashMap;
import java.util.Map;
import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    Scanner in = new Scanner(System.in);
    Map<String, Integer> tally = new LinkedHashMap<>();
    while (in.hasNextLine()) {
      String vote = in.nextLine().trim();
      if (vote.isEmpty()) continue;
      tally.merge(vote, 1, Integer::sum);
    }

    String winner = null;
    int best = 0;
    for (Map.Entry<String, Integer> e : tally.entrySet()) {
      if (e.getValue() > best) {
        best = e.getValue();
        winner = e.getKey();
      }
    }
    System.out.println(winner + " wins with " + best + " votes");
  }
}
`,
    },
  ]}
  tests={[
    {
      id: "winner",
      name: "Prints the winning vote and its count",
      description: "Exact stdout match (trimmed)",
      expect: { stdoutEquals: "red wins with 3 votes" },
    },
  ]}
/>
